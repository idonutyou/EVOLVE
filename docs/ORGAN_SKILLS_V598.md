# WEB-31 장착 무기와 부위별 스킬

메인 화면은 스테이지 번호·맵 이름·클리어(또는 잠김)·전투 시작만 표시합니다. 미니어처의 원본 바이트는 유지하고 5.5초에 걸쳐 위아래 16px 범위를 움직입니다. 접근성의 움직임 줄이기 설정은 그대로 적용합니다.

무기 선택 화면과 그 연결 코드는 삭제했습니다. 전투에 진입하면 플레이어 레벨 1에서 즉시 기존 레벨업 카드 3개가 나옵니다. 장착한 팔의 강화 하나와, 서로 다른 두 부위의 공격 습득 선택지입니다. 초기 경험치나 플레이어 레벨은 증가하지 않습니다. 팔은 선택과 관계없이 1레벨이며, 다른 공격은 습득 전에는 0레벨이라 발사하지 않습니다.

| 부위 | 런타임 키 | 기존 장비 슬롯 | 기본 공격 |
| --- | --- | --- | --- |
| 팔 | arm | arm | 실제 장착 총·칼. 미장착이면 기본 찌르기 |
| 외피 | shell | skin | 유도 가시 한 발. 한 적 명중 후 소멸 |
| 꼬리 | tail | tail | 실제로 휘두른 궤적만 타격하는 채찍과 밀치기 |
| 입 | mouth | head | 직선으로 발사하는 기본 침. 기본에는 독·부식 없음 |

발사 수·관통·속도·사거리, 채찍 공격 각도·범위·밀치기를 카드로 키웁니다. 최대치에 도달한 강화는 더 나오지 않으며 남은 증가량만 표시하고 적용합니다. 기존 체력·방어·이동 속도 같은 수동 보너스 카드도 이후 레벨업에서 유지합니다. 장착 팔과 다른 무기 카드는 나오지 않습니다.

## 이후 아이템 연결

`web/organ-skill-model-v598.js`는 공격 형태·속성·색과 충돌 범위를 정의하고, `web/organ-skills-v598.js`는 발사·명중·렌더링·카드·수명 관리를 담당합니다. 장비 ID와 저장 키는 바꾸지 않았습니다.

새 아이템을 만들 때 카탈로그 항목에 다음 메타데이터를 연결할 수 있습니다.

```js
{id:'future_fire_head',slot:'head',skillVariantsV598:{mouth:'fire_breath'}}
{id:'future_ice_skin',slot:'skin',skillVariantsV598:{shell:'ice_spike'}}
{id:'future_poison_tail',slot:'tail',skillVariantsV598:{tail:'poison_whip'}}
```

기존 아이템에는 아직 이 매핑을 붙이지 않았습니다. 현재의 기본 공격을 유지하면서 새 아이템의 독침·화염 브레스·얼음침/브레스 등을 연결할 수 있도록 프로필과 실행 경로를 준비했습니다. 브레스에는 무의미한 투사체 수·관통 카드가 나오지 않습니다. 다른 슬롯의 프로필을 잘못 붙이면 기본 형태를 사용하고, 레벨 0에서는 어떤 프로필도 발사하지 않습니다.

투사체는 실제 벽과 적의 충돌 원을 검사하고, 빠르게 지나간 구간도 검사합니다. 기본 가시는 피해를 주면 즉시 제거되고, 관통을 배우면 같은 적을 재타격하지 않고 다른 적을 맞춥니다. 채찍은 준비 동작 후 실제 궤적에 닿은 적을 한 번씩 타격하며 벽 너머에는 닿지 않습니다. 일시 정지에서는 멈추고 홈·새 전투 진입 시 실행 중인 투사체와 효과를 지웁니다.

실행 검사는 `tests/organ_skills_browser.cjs`, 충돌 수학 검사는 `tests/organ_skills.test.cjs`에 있습니다. 관리자 모드의 진입 후 소환 요청은 첫 스킬 선택을 끝낼 때까지 기다립니다. 물리 휴대폰 성능 검사는 수행하지 않았습니다.
