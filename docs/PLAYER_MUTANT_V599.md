# 확정 캐릭터 적용 — V599

사용자가 승인한 회보라색 갑각·붉은 근육·청록색 코어 캐릭터를 사용한다.
가까운 무기 팔의 위치와 원근 크기, 짧은 기본 꼬리는 승인한 원본을 따른다.

- 네 보행 다리는 대각선 두 쌍으로 디딤과 들어올림을 번갈아 수행한다.
- 디딤 중 발의 위치를 유지하고 몸통과 관절이 이동을 따라가도록 한다.
- 정지 시 발을 부드럽게 회수하고, 몸통의 호흡과 공격·피격 반응을 더한다.
- 기존 총과 칼의 장착 ID, 피해량과 공격 범위는 유지하고 새 손목 위치에 연결한다.
- 꼬리 0레벨은 승인된 짧은 꼬리다. 배운 뒤에는 기존 강화 수치에 맞는 갑각 마디 꼬리를 사용한다.
- 채찍 타격 시간과 범위는 기존 스킬 모델을 사용하며, 보이는 꼬리 끝도 같은 궤도를 따른다.
- 원본 PNG와 기존 게임 이미지는 다시 인코딩하지 않는다. 부위 선택과 관절 정보만 별도로 둔다.
- 실제 Galaxy S23+의 장시간 발열·FPS를 검증한 것으로 표현하지 않는다.
