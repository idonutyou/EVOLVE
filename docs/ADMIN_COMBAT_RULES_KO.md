# WEB-29 관리자·몬스터·중간보스

기준: WEB-28 (`3f8f3164bc19d89fb67d4ea95069674f9fcba1ab`). 사용자 추가 요청을 포함한 WEB-29 변경이다.

- 크롤러·러너·브루트·스피터는 기존 원본 외형을 사용한다. 새 모션 시트의 고유 외형 3종은 리퍼(`ripper`), 파쇄자(`mauler`), 독낭수(`bileback`)라는 독립 종류다. 크롤러·러너에 같은 새 외형을 중복 배정하지 않는다.
- 신규 종류의 기본 전투 역할은 각각 러너·브루트·스피터에서 상속한다. 4·7·9스테이지부터 해당 역할의 자연 소환 중 24%로 등장하며 원래 종류도 계속 등장한다. 총 소환 수를 추가하지 않는다. 관리자 목록은 보스를 제외한 19개 항목이다.
- 전투 시작은 시작 무기 선택으로 바로 이어진다. 계약 선택·위험도·연속 계약 보너스·계약 코어·전투 중 계약 판정·실패 페널티·계약별 TITAN 보정·결과 문구를 제거했다. 옛 저장의 계약 기록 필드는 가져오기 호환을 위해 읽되 플레이에 사용하지 않는다. 저장 키와 기존 재화는 보존한다.
- 관리자 활성화 직후 저장된 시험용 맵을 즉시 준비한다. 이미 준비한 동일 맵은 재사용한다. 관리자 종료 시 일반 진행의 스테이지·맵으로 복귀한다.
- 모든 살아 있는 몬스터는 전투 역할과 무관하게 접촉 피해를 준다. 러너의 평상시, 원거리와 지원형도 포함한다. 기존 피격 무적과 접촉 재사용 간격은 유지한다.
- 스피터·프로스트 스토커·독낭수는 가까워지는 플레이어에게서 후퇴하며 옆으로 움직이고 발사한다. 근접·돌격형은 준비·돌진·피격 상태를 제외하면 플레이어에게 지속 접근한다. 이동은 기존 지형 조향과 충돌 처리를 통과한다.

## 검증

기존 모바일 세로·가로 화면, 무기, 강화, 저장, 맵 편집, BIO·VENOM 페이즈와 공격 경고 검사도 유지한다. Galaxy S23+ 실기 성능이나 최종 난이도 체감은 자동 검사로 확정하지 않는다.
