EVOLVE V575 — 전체 게임 수동 업로드 안내

이 ZIP에는 V575 온라인 게임 전체 데이터가 들어 있습니다.
이미지 977개는 원본 바이너리를 그대로 보존했습니다. 이미지 재압축/리사이징을 하지 않았습니다.

중요: ZIP 자체를 GitHub에 올리는 것이 아닙니다.
압축을 풀고 UPLOAD_FILES 폴더 안의 파일 68개를 올립니다.
BIN 67개 + EVOLVE_V575_INSTALL.json 1개이며 모두 필요합니다.
파일 이름을 바꾸거나 ZIP 안에서 직접 파일을 선택하지 마세요.

최초 1회: GitHub Pages 설정
- Chrome에서 https://github.com/idonutyou/EVOLVE/settings/pages 를 엽니다.
- Build and deployment의 Source를 GitHub Actions로 선택합니다. 이미 선택되어 있으면 그대로 둡니다.
- 이 설정은 GitHub 앱 재연결/권한 설정과 별개인 웹사이트 게시 방식 선택입니다.

휴대폰 업로드 (삼성/안드로이드 Chrome)
1. ZIP을 다운로드한 후 '내 파일' 앱에서 압축을 풉니다.
2. Chrome에서 아래 주소를 엽니다. GitHub 앱으로 열렸다면 주소를 Chrome 주소창에 직접 붙여넣으세요.
   https://github.com/idonutyou/EVOLVE/upload/main
3. Chrome 오른쪽 위 메뉴(점 3개)에서 '데스크톱 사이트'를 켭니다.
4. GitHub 계정 idonutyou로 로그인된 상태에서 'choose your files'를 누릅니다.
5. 압축을 푼 폴더 > UPLOAD_FILES로 들어가 파일 68개를 모두 선택합니다.
   파일 선택 창에서 파일 하나를 길게 누르면 다중 선택/전체 선택이 나올 수 있습니다.
6. 업로드가 모두 끝날 때까지 Chrome을 열어 두세요. Wi-Fi 사용을 권합니다.
7. 아래 'Commit changes'를 눌러 main 브랜치에 저장합니다.
8. 다음 주소에서 'Publish EVOLVE Web' 작업을 엽니다.
   https://github.com/idonutyou/EVOLVE/actions
9. 'Deploy GitHub Pages' 단계까지 성공한 후 표시되는 page_url 주소로 게임에 접속합니다.
   업로드만 끝난 시점에는 아직 배포 완료가 아닙니다.

한 번에 업로드가 어려운 경우 (이어 올리기)
- BIN 파일을 10~15개씩 나눠 업로드하고, 매번 Commit changes를 누르세요.
- 001~067번 BIN을 모두 올린 다음 EVOLVE_V575_INSTALL.json을 마지막에 올리세요.
- 이미 정상 등록된 BIN 파일을 처음부터 다시 올릴 필요는 없습니다.
- 68개 전부를 선택했는데 브라우저가 느리면 이 방법으로 진행하세요.
- JSON을 먼저 올려 누락 파일 오류가 났다면, 남은 BIN을 올린 후 Actions에서 해당 작업의 Re-run all jobs를 누르세요.
- 반드시 저장소 최상위(main)에 파일을 올리세요. UPLOAD_FILES라는 하위 폴더를 GitHub에 만들지 마세요.

컴퓨터 업로드
1. ZIP 압축을 풉니다.
2. https://github.com/idonutyou/EVOLVE/upload/main 을 엽니다.
3. UPLOAD_FILES 안의 파일 68개를 업로드 영역에 끌어 넣습니다.
4. 전송이 끝나면 Commit changes를 누르고 Actions 결과를 확인합니다.

설치/배포 동작
- 저장소에는 수동 업로드 복원 프로그램과 배포 작업이 준비되어 있습니다.
- 각 BIN의 크기/SHA-256, 전체 압축 묶음 SHA-256, 복원한 이미지/코드 1001개의 SHA-256을 확인합니다.
- 검증한 dist/index.html, dist/assets와 나머지 게임 파일을 자동 생성합니다.
- 브라우저 실행 검사를 통과한 뒤 전체 게임을 main에 기록하고 GitHub Pages에 배포합니다.
- 필수 파일이나 이미지 검증이 실패하면 배포가 중단됩니다. 빈 사이트를 올리지 않습니다.
- 브라우저 자동검사와 실제 휴대폰 플레이 검사는 다릅니다. 업로드 후 실행 검사가 아직 남아 있습니다.
- 앞으로 main에 게임이 설치되면 이전 최초 설치 묶음으로 자동 덮어쓰지 않습니다.

저장 데이터
- 같은 온라인 주소에서의 새로고침/게임 업데이트는 기존 저장 키를 유지합니다.
- 휴대폰에서 열던 예전 HTML 파일과 새 HTTPS 주소는 브라우저 저장 공간이 다릅니다.
- 예전 진행 상황을 옮기려면 원본 게임의 설정에서 저장 내보내기를 하고, 온라인 게임에서 가져오기를 하세요.
- 온라인 게임에서 기존 진행 상황을 확인하기 전까지 원본 파일/백업을 보관하세요.
