# EVOLVE WEB-43 화면 복원 및 레벨업 UI

공개 게임: https://idonutyou.github.io/EVOLVE/

가시·채찍은 원본 PNG의 무기 부분을 기존 카드의 작은 그림 영역에 배치하고 밝기·채도를 낮췄다. 기존 스킬과 같은 등급 프레임을 사용한다. 강화 이름·설명·레벨·능력치·클릭 처리는 기존 게임 값을 그대로 따른다. 원본 이미지 1,019개의 바이트는 변경하지 않았다.

다시 뽑기는 상단 레벨업 창과 같은 푸른 패널로 표시하며 안쪽 색 채움이 바깥 테두리를 가리지 않도록 수정했다. 붉은 장식 내부는 불투명하고 바깥으로만 게임 화면이 보이는 기존 요청을 유지한다.

전투 시작 시의 화면 크기를 고정해 시스템 바가 나타나거나 사라져도 게임·선택창의 크기와 위치가 변하지 않는다. 실제 가로·세로 방향 전환과 홈 복귀에는 새 화면에 맞게 처리한다. 앱 복귀, BFCache 복귀, 그래픽 컨텍스트 복원 시 세계·캐릭터·카드·하단 아이콘을 원본 이미지에서 다시 그린다. 카드를 다시 뽑거나 전투 시간을 진행하거나 저장 키를 바꾸지 않는다.

게임 엔진 변경은 화면 크기와 그래픽 복원에만 한정했다. 해당 렌더링 변경 4개를 역으로 적용하면 기준 커밋 9cb02fe7ec2e21ea23b32d74febdeb2f82ed5e9d의 엔진과 정확히 일치한다. 원본 PNG 파일 재압축·축소·재생성은 하지 않았다.

브라우저 검사 25개와 실제 공개 사이트 검사 7개를 통과했다. 공개 파일 9개의 바이트 일치를 확인했다. 앱 복귀·BFCache·그래픽 복원 뒤 글씨와 그림을 확인했고, 시스템 바에 따른 화면 크기 유지를 검증했다.
