# EVOLVE WEB-42 채찍·가시 레벨업 카드

공개 게임: https://idonutyou.github.io/EVOLVE/

사용자가 제공한 채찍 5장과 가시 5장의 PNG를 커먼·레어·에픽·전설·신화에 각각 연결했다. 원본 파일 10개는 재생성·재압축하지 않고 바이트 그대로 사용한다. 새 프레임과 그림에 기존 게임의 카드 이름·레벨·효과·부위 문구를 표시한다. 이미지에 적힌 예시 문구가 실제 효과를 대신하지 않는다.

게임 엔진과 기존 자산 1050개는 기준 커밋 449773f580453ed46e0f37502e0ac00e1c44a298과 바이트 단위로 일치한다. 카드 선택 처리·공격력·발사 수·범위·강화 효과·저장 키를 유지했다. 다른 카드와 전투 중 스킬 모양은 변경하지 않았다. 표시용 원본 이미지 캐시는 최대 3개다.

브라우저 검사 24개와 공개 사이트 검사 6개를 통과했다. 실제 공개 파일 16개 및 원본 PNG 10개의 일치를 확인했고, 모든 등급의 표시와 실제 카드 클릭에 따른 기존 강화 수치를 검증했다. 자동화한 휴대폰·가로 화면 검사이며 실제 Galaxy S23+ 기기 시험은 아니다.
