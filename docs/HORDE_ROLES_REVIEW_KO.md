# EVOLVE WEB-24 — 몬스터 역할과 물량, 레벨 제한

직전 실제 배포본 WEB-23을 기준으로 수정했다.

- 방전 파동의 확산 시간을 0.78초에서 1.56초로, 전체 지속 시간을 1.18초에서 2.36초로 늘렸다. 중심 섬광과 전기 선의 시간 변화도 절반 속도로 맞췄다. 충전 3초, 재생성 60초, 굵기와 도달 가능한 맵 전체 무작위 생성은 유지했다.
- 일반 몬스터의 이동과 돌진 속도를 기존의 절반으로 줄였다. 투사체 속도와 공격 주기는 유지했다.
- 일반 물량은 생성 빈도와 밀도 목표를 1.5배로 높였고 습격 물량도 약 1.5배로 늘렸다. 기존 동시 등장 상한과 보스 조우의 물량 조절은 유지했다.
- CRAWLER·BRUTE는 근접형, RUNNER·EMBERMAW는 돌격형, SPITTER·FROSTSTALKER는 원거리형, WARDEN·SYMBIOTE는 지원형으로 고정했다. 원거리·지원형의 접촉 피해를 없애고 돌격형은 돌진 중에만 충돌 피해를 준다. 일반 SPITTER의 바닥 장판, FROSTSTALKER의 별도 광선, EMBERMAW의 용암 장판을 제거했다. BRUTE는 근접 거리 안에서만 내려찍기를 준비한다.
- 일반 몬스터의 공격 범위 표시는 끄고 보스·중간보스·정예 조우와 환경 위험의 표시는 유지했다.
- 스테이지 내 Lv.10 제한을 해제했다. 경험치 초과분을 버리지 않고 이후 레벨업과 강화 선택을 계속 제공한다. 홈에는 제한 없음으로 표시한다.

## 확인

실제 게임의 이동 거리·접촉 피해·투사체·돌격·공격 범위 그리기와 30초 물량을 검사했다. 동일 시점의 기존 밀도 목표 12마리에 대해 실제 18마리가 유지됐다. Lv.10·11·25·100에서 강화 선택 버튼과 초과 경험치 보존을 확인했다. 직전 이동·무기 방향 및 다섯 맵의 240회 방전 장치 생성, 느려진 파동과 기존 방전 피해 검사도 통과했다. 기존 이미지 994개를 바이트 단위로 보존했다.

자동 업로드·배포와 서버 전체 검사를 완료했다. 공개 사이트의 버전·매니페스트·실행 파일 SHA-256·진입 HTML이 최종 WEB-24 빌드와 일치한다. 배포 기록은 `WEB24_PUBLISH_WORKFLOW.json`, 실제 사이트 검증은 `HORDE_ROLES_LIVE_REPORT.json`에 저장했다. Galaxy S23+ 실기 검사는 수행하지 않았다.
