# EVOLVE 맵 제작·업데이트 고정 규칙

사용자 확정: 2026-10-21. 아래 규칙은 이후 맵 작업에도 적용한다.

## 빠른 저장 JSON 반영 절차

현재 배포본 dist/가 작업 기준이다. 이미 있는 맵의 승인된 저장 JSON을 반영할 때는 먼저 현재 배포 데이터와 내용이 같은지 비교한다. 같으면 다시 패치하거나 전체 게임을 재생성하지 말고 실제 Pages 배포와 버전을 확인해 완료를 보고한다.

1. 저장 JSON의 format/version/mapId/baseFieldSha256/reference/field/operations/entrances를 해당 맵과 검증한다. 다른 맵이나 다른 기준 충돌 해시의 파일을 강제로 적용하지 않는다.
2. 현재 사용 중인 승인 데이터 스크립트와 비교하고 실제 달라진 데이터만 교체한다. 원본 이미지, 다른 맵, 게임 엔진, 보스 코드를 다시 처리하지 않는다.
3. 변경 자산의 SHA-256 이름, asset-manifest.json, index.html의 참조·바이트 수, EVOLVE_WEB_CONFIG 및 version.json의 build/version, verification.json을 함께 갱신한다. 기존 사용자 저장과 승인 편집은 유지한다. 호환되는 개인 편집이 있으면 기존 편집 우선 원칙을 유지하며, 새 배포 기본값 때문에 덮어쓰지 않는다.
4. JSON 형식·맵 일치·데이터 동등성·참조/해시·기존 저장 보존을 확인하고 필요한 변경 범위의 실행 검사를 한다. 기존 배포 검사를 유지하고 실제 Pages 배포 성공 및 공개 URL의 version.json/변경 자산 해시까지 확인한다.
5. 파일 확인→수정→검증→배포의 결과를 짧게 남겨 중단 후 해당 지점부터 재개한다. 완료한 전체 변환·이미지 분석·과거 버전 검사를 반복하지 않는다.

저장 JSON만 교체하는 일반 업데이트는 약 5분을 목표로 한다. GitHub 대기·오류·네트워크 시간 때문에 5분 완료를 보장하지 않는다. 새 이미지의 맵 제작과 충돌영역 신규 설계는 별도 작업량이다. 실행하지 않은 검사를 통과했다고 보고하지 않는다.

확인 사례: FACILITY1 저장본(341 operations / 7,844 points)은 main의 30104fb81a44d6ec32e7b43d80f9af9ef9098a3c에 반영됐다. Publish EVOLVE Web 실행 39544547162는 04:31:55Z~04:33:40Z 약 1분 45초에 성공했고, 브라우저 검사는 13초였다. 공개 배포는 V575-WEB-3이다. 이 값은 사례이며 앞으로의 최신 기준을 이 커밋으로 고정하지 않는다.

## 1. 작업 기준

- 사용자가 첨부한 최신 게임 HTML 또는 요청한 현재 온라인 배포본을 기준으로 한다. 과거 버전으로 임의 복귀하지 않는다.
- 시각 표현은 V575에서 확정한 방식을 사용한다. 제공 이미지의 구조물 배치·통로·구도를 유지한다.
- 사용자가 수정한 맵이나 충돌 JSON을 우선 적용하고 테스트한다. 확정한 충돌영역을 다시 추정하지 않는다.
- 적용 스테이지는 사용자가 지정한 경우에만 변경한다. 미지정이면 기존 배치를 유지하고 TEST 메뉴에서 새 맵을 선택할 수 있게 한다.

## 2. 이미지 크기와 화질

- 기준 완성 해상도는 1882×3344px이다. 941×1672px 이미지 4장은 1 좌측 상단 / 2 우측 상단 / 3 좌측 하단 / 4 우측 하단으로 정확히 합친다.
- 임의 자르기·늘리기로 비율을 바꾸지 않는다. 연결부의 겹침·누락·이음새를 확인한다.
- 고해상도 원본이나 분할 자산이 있으면 실제 해당 자산을 사용한다. 원본을 보존하고 임의 재압축·축소하지 않는다.
- 단순 확대를 세부 묘사가 개선된 고화질로 보고하지 않는다.
- 이미지 해상도가 게임 맵 크기·캐릭터 크기·카메라 배율·공격 사거리를 바꾸면 안 된다.

## 3. 바닥 표현과 전투 가시성

- V575 처리 코드를 재사용한다. 기본 보정: 채도 0.75 / 밝기 0.82 / 대비 0.92. 바닥 세부 명암 유지값: 0.42.
- 이동 가능한 바닥의 균열·자갈·철망·반사 무늬의 국소 명암 대비를 낮춰 몬스터 가시성을 확보한다. 구조물·벽·펜스·독액 경계는 구분되게 유지한다.
- 전체 흐림이나 해상도 저하로 처리하지 않는다.
- 아주 가는 붉은 몬스터 윤곽선과 하늘색 캐릭터 윤곽선을 유지한다. 두껍게 하거나 발광·번짐을 추가하지 않는다.
- 보스 이미지·모션·이펙트·공격 예고 표현을 임의 변경하지 않는다.

## 4. 충돌영역

- 최종 화면 이미지와 좌표를 정확히 맞춘다. 새 맵에 이전 맵의 충돌 도형을 재사용하지 않는다.
- 건물·탱크·기계·상자·드럼통·벽·펜스·기둥·바리케이드·지면을 막는 파이프와 큰 돌은 실제 형태대로 막는다.
- 바닥의 평평한 배수구·하수구 덮개·철망·맨홀·바닥 표시는 통행 가능하다. 세워진 철망문·바리케이드와 구분한다.
- 얇고 긴 펜스·파이프·구조물 연결부·틈새를 확인한다.
- 기존 발 충돌 크기로 실제 통로를 지나갈 수 있게 한다. 구조물 내부의 좁은 틈을 통로로 열지 않는다.
- 기존 발 기준 충돌 방식·이동 처리를 유지한다. 일반 이동·대시·밀림·몬스터 추적의 벽 관통·끼임을 검사한다.
- 확대·축소·DPR·화면 크기 변경에도 이미지와 충돌 좌표가 일치해야 한다.

## 5. 몬스터 진입로

- 사용자가 표시한 진입로를 우선 사용한다. 표시가 없으면 이미지에서 실제 외부와 연결된 열린 길만 사용한다.
- 일반 몬스터는 각 진입로의 맵 바깥쪽 끝에서 생성되어 길을 따라 진입한다. TEST 50·100·200마리 소환에도 동일 규칙을 적용한다.
- 건물 내부·탱크·펜스 뒤·독액 시설·플레이어 주변 임의 위치에서 생성하지 않는다.
- 각 진입로에서 실제 전투 공간까지 연결되는 경로를 확인한다. 막힌 진입로는 사용하지 않는다.
- 생성 공간이 부족하면 기다리며 임의 위치로 옮겨 생성하지 않는다.
- 보스 등장·봉쇄·증원은 최신 게임 규칙을 유지한다.

## 6. 환경 효과

- 이미지의 녹색 연기 위치에서 부드럽게 피어오르고 흩어지는 연기를 표현한다. 녹색 독액 내부에서 기포가 올라오고 터지게 한다.
- 효과가 벽·기계·일반 바닥으로 새지 않게 범위를 맞춘다. 연기는 V575 가시성 수준을 유지한다.
- 녹색 유독가스 근처에서는 기존처럼 플레이어가 느려지고 벗어나면 정상 속도로 복귀한다.
- 별도 요청 없이 환경 독 피해나 새 상태이상을 추가하지 않는다.

## 7. 성능과 기존 기능 보존

- 바닥 보정·윤곽선은 준비 시 처리해 재사용한다. 매 프레임 전체 이미지 분석·필터 계산·외곽선 생성을 하지 않는다.
- 맵 효과는 화면에 보이는 범위와 기존 개수 제한을 사용한다. 이전 맵 캐시가 계속 쌓이지 않게 한다.
- BIO·VENOM AI·스킬·페이즈·밸런스 및 정상 전투·성장·저장·보상을 임의 변경하지 않는다.
- TEST 메뉴와 충돌 편집·저장·불러오기를 유지한다. 사용자의 저장 기록과 승인한 맵 편집을 보존한다.

## 8. 검사와 결과 제공

- 실제 최종 이미지가 들어간 배포 HTML로 실행 검사한다.
- 새 맵의 전체·확대 화면에서 충돌·통로·배수구·펜스·바리케이드·구조물 틈·맵 가장자리를 확인한다.
- 각 진입로의 생성 위치·진입 경로 및 50·100·200마리 소환을 검사한다.
- 해당 맵의 보스 경고→등장→봉쇄→전투를 확인한다.
- 자동 검사와 Galaxy S23+ 실기 결과를 구분한다. 확인하지 않은 휴대폰 성능을 해결됐다고 보고하지 않는다.
- 실제 수정된 HTML 또는 ZIP을 제공한다. 긴 게임 소스를 채팅에 붙이지 않는다.
- 변경 내용·실제 이미지 해상도·활성 진입로·검사 결과·미검증 항목을 짧게 정리한다.
