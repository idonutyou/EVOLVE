# 캐릭터 자동 환경 조명 V627

기준: main dca540e54419393191920aab7908cc65bb609e9d, build b6daa0894769f43e5f922f6b5e141efe57cf62b9a8609f6f4eabef4215f7c28c.

- 현재 맵에 표시되는 이미지를 축소 표본으로 한 번 분석해 조명값을 계산하고 같은 맵의 결과를 재사용한다.
- 캐릭터 본체와 장착 코어에 같은 표시 처리를 적용한다. 코어의 종류별 수동 설정은 만들지 않고 원본 색과 이미지를 보존한다.
- 그림자는 표시 프레임의 실루엣을 바탕으로 생성해 재사용한다. 이동, 전투, 충돌, 저장과 홈 미리보기는 바꾸지 않는다.
- 맵에 이미지가 없거나 표본을 읽지 못할 때는 무리한 색 조정 없이 안전하게 표시한다.
- 맵 색감은 환경에 대한 근사값이며 개별 조명 위치를 실시간 추적하는 시스템은 아니다.
