# EVOLVE WEB-25 — 체력바와 전투·출현 경고 정리

WEB-24 실제 배포본을 기준으로 수정했다.

- 습격 대상의 주황색 원과 등장 시 장식 원을 일반 렌더링·GPU 렌더링에서 모두 제거했다. 습격 판정과 등장 로직은 유지했다.
- 기존에 일부 종류만 항상 표시하던 체력바를 제거했다. 모든 일반 몬스터와 정예는 피격 후 1.2초 동안만 체력바를 표시하며 재피격하면 시간을 갱신한다. 실제 렌더링된 몸의 높이·회전·좌우반전·기울기를 기준으로 위에 4월드 픽셀 이상 띄운다. 바는 몸과 전경을 그린 다음에 그린다. 일시정지 중에는 표시 시간이 멈추며 죽거나 전투를 나가면 없어진다. 최종 보스 전용 상단 HUD는 유지한다.
- 베놈의 나란한 산성 탄막·독침 예고를 개별 사각형 대신 전체를 감싸는 하나의 외곽으로 합쳤다. 모든 유효한 탄도 영역을 포함하는 보수적인 외곽이며 실제 투사체와 피해 판정은 바꾸지 않았다. 방사형 독샘 탄막도 하나의 큰 원형 예고를 쓴다. 완전히 막힌 탄도에는 빈 경고를 그리지 않는다.
- 보스 출현 경고 띠와 기존 그림 글씨를 한 캔버스의 같은 중심·기울기·이동 좌표로 그린다. 글씨와 띠가 함께 초당 40 CSS 픽셀로 이동하며 기존 글씨 속도는 27이었다. 빛바랜 산화철·금속 질감은 한 번 만들어 캐시한다. 동작 줄이기 설정도 유지한다.
- ‘초대형 생명체’와 영문 대응 문구를 출현 화면에서 제거했다. 기존 보스 이름, 문양, 숫자와 한글 그림 글씨 원본은 유지했다.

## 검사

8종 몬스터와 기존 두 외형에 실제 공격을 가해 체력바가 피격 때만 나타나는지, 몸 위에 배치되는지, 사라지고 갱신되는지 확인했다. 일반·GPU 표시 경로와 일시정지도 검사했다. 실제 베놈 산성 탄막 5줄과 독침 14줄이 각각 경고 한 개로 표현되며 독샘 예고도 한 개다.

세로·가로 화면과 BIO·VENOM 출현 연출에서 글씨의 중심·띠의 중심·이동량이 일치하고 자막이 보이지 않는 것을 확인했다. 한글·영문과 실제 보스 출현·무적 등장·정지·기존 단축 조우 및 모든 보스 공격 예고 검사를 통과했다. 실제 화면도 확인했다. 원본 이미지 994개, 맵·저장 키·플레이어 공격과 몬스터의 이동·피해 로직은 유지했다.

자동 배포와 공개 사이트 검증은 완료 후 기록한다. Galaxy S23+ 실기 검사는 수행하지 않았다.
