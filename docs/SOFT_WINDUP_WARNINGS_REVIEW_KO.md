# WEB-16 · 시전 전 예고만 은은하게 표시

사용자 피드백: 붉은 영역이 너무 강하고 공격이 발동한 뒤에도 경고 범위가 남아 화면을 가렸다.

- 내부 채움 불투명도를 30%에서 7.5%로 낮췄다.
- 검고 굵은 이중 테두리를 없애고 1.25px의 반투명 붉은 선을 사용한다.
- BIO와 VENOM의 예고는 시전 준비 중에만 표시한다. 발동한 돌진, 부채꼴 공격, 충격파, 독안개, 감염 전선 및 장판 위의 추가 경고 덮개는 사라진다.
- 실제 독안개·장판·타격·투사체의 기존 이펙트는 유지한다. WEB-15의 경고 통합 과정에서 대체되었던 일반 독/공허 장판과 환경 장판은 기존 활성 상태 그림을 복구했다.
- VENOM 감염의 두 번째 발사는 별도의 실제 준비 시간에만 잠깐 예고하고 발사하면 지운다. 아직 터지기 전의 지연 장판은 그 장판의 준비 시간이 끝나면 예고를 지운다.
- 예고를 맵 전경 위에 그리는 순서, 안전 지대, 벽에 막히는 범위와 실제 판정은 유지한다.

기준은 배포된 WEB-15 커밋 `6fabbfbed161b077707ca704cf080f13ec36c762`이다. 패키징 도구는 예고 모듈·호출부와 활성 장판 렌더링 복구를 제외한 엔진 전체가 기준과 동일한지 검증한다. 이미지 984개의 원본 바이트를 변경하지 않았다.

자동 모바일 브라우저에서 세로/가로 화면, BIO 10종과 VENOM 세 페이즈, 일반 예고 27종, 안전 지대 및 실제 맵 전경을 검증한다. 물리 Galaxy S23+ 시험은 수행하지 않았다.

실행: `python3 tools/package_soft_warnings_v583.py`, `python3 tools/verify_site.py --dist dist`, `node tests/attack_warnings_browser.cjs` 및 기존 회귀 검사. 승인된 기존 GitHub Pages 경로로 자동 업로드 및 배포한다.
