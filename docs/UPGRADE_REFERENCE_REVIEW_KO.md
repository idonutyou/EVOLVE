# WEB-27 강화창 원본 복원과 몬스터 표시 정리

기준: WEB-26 최종 main `79ea7d94d753f67fd59b491a40ddecd1041b711e`.

- 첨부 `1000027564.png`의 실제 픽셀을 배경·배너·프레임·부위 아이콘에 사용한다. 원본은 JPEG 형식이며 파일 바이트를 그대로 보존해 등록했다. 새로운 배경을 생성하지 않는다.
- 현재 레벨은 별도로 표시한다. 기존 둥근 외곽 패널은 제거한다.
- 이름과 능력 수치는 독립된 화면 합성 층에 표시해, 여러 번 레벨업한 뒤 일부 글자가 가려지는 현상을 방지한다.
- 장비 그림은 승인된 등급별 아틀라스의 원본 바이트를 유지한다. 더 넓은 영역에서 물체를 분리하고, 주변 이미지 조각을 제외한 뒤 64픽셀 투명 여백 안에 비율을 유지해 표시한다. 광채는 물체 외형을 따라 다시 그려 사각형 경계와 위아래 잘림을 없앤다.
- 총/칼의 부위 표시는 모두 `팔`, 뒷발은 `발`, 외피는 `외피`다.
- 총·칼 장착 카드 2종을 제거했다. 강화 카드는 17종이다. 팔 강화는 현재 활성화해 착용한 총 또는 칼에 해당하는 능력만 추첨한다. 장비가 없는 팔에는 총·칼 전용 카드를 주지 않는다. 기존 캐릭터의 발·외피 강화는 유지한다.
- 레벨업 선택으로 장비가 교체되지 않는다. 3장 선택과 모든 레벨 경험치 12, 레벨 제한 없음은 유지한다.
- 정예의 빨간 삼각형 몸 장식과 정예 속성 원, 네메시스, 노출/보호막/기절/대상 표시, 지원 오라와 우선순위 배지를 일반·중간보스·보스의 CPU/GPU 표시 경로에서 제거한다. 실제 공격 경고, 피해 처리, 보호막 기능, 피격 체력바와 몬스터 그림은 유지한다.
- 새 시안 승인이나 업로드 확인을 다시 묻지 않고, 검사 후 자동 배포한다.

작업 진행 및 최종 검증은 `upgrade-reference-v594-checkpoint.json`에 기록한다. 자동 브라우저 검사와 실제 Galaxy S23+ 확인을 구분한다.

- 총/칼/미장착 상태별 실제 추첨 300회, 장비 교체 카드 없음.
- 25종 등급별 그림 투명 여백, 원본 프레임 857픽셀 일치, 현재 레벨과 팔/발/외피 표시 확인.
- 정예 속성·네메시스·중간보스·보스의 CPU/GPU 몸 표시 18경로 확인 및 실제 GPU 상태 장식 인스턴스 0개.
- 전투·피격 체력바·베놈 통합 경고·기존 경고 연출 브라우저 검사와 Python/클라이언트 검사 통과.
