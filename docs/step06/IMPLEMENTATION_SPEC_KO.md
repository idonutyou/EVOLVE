# STEP 06 / 1-of-3 설계 완료 — 다음 구간 구현 명세

## 범위와 이미지

가시·채찍·전격 3종의 타격 반응만 다룬다. 침은 STEP06 작업 대상에서 제외했다. 게임의 입 장비/강화 카드/보스 패턴을 삭제한 것으로 간주하지 않는다. 기존 확정 가시·꼬리 외형과 크기를 보존한다. 설계 구간에는 이미지 생성·렌더링이 필요 없다. 구현 구간에서는 먼저 기존 효과와 신체 모션을 사용한다. 새 텍스처가 꼭 필요하다면 실제 생성 전에 별도 사전 고지한다.

| 종류 | 목표 느낌 | 연결점 | 구현 제한 |
|---|---|---|---|
| 가시 | 명중 방향으로 국소적으로 눌린 뒤 즉시 복귀하는 관통감 | organProjectileStepV598 → organHitV598 / spike | 실제 직접 명중만 반응, 관통 횟수·피해·유도·크기 유지 |
| 채찍 | 휩쓸기 방향의 짧은 비틀림과 복귀 | organWhipStepV598 → organHitV598 / tail | 기존 밀치기 방향을 시각적으로 사용, 추가 이동·넉백·경직 없음 |
| 전격 | 기존 연쇄 타이밍에 맞는 순간 떨림과 반응 분리 | lightningV576 / arc | 기존 전격 피해·연쇄·정지 시간을 바꾸지 않고 기존 반응 우선 |

시험용 시각 수명 후보는 가시 0.09~0.13초, 채찍 0.12~0.17초다. 아직 구현하거나 검증한 수치가 아니다. 기존 일반 몬스터/중간보스/TITAN 크기에 맞춰 변형 강도를 줄이고, 적의 충돌 좌표와 신체 파츠 연결 위치는 그대로 둔다. 큰 피해 반응은 실제 체력 감소·치명타 메타데이터를 읽고, 틱 피해를 큰 충격으로 반복 표현하지 않는다.

## 구현 방법

1. 기존 EVOLVE_HIT_EVENTS schema 1과 STEP05 총·칼 피드백을 유지한다. 새 시각 전용 모듈을 구독하고 동기 콜백 동안 실제 대상 참조를 사용한다. 대상은 WeakMap으로 관리하고 종료·귀환·재시작 때 반응을 초기화한다.
2. 직접 투사체 및 채찍 명중 호출에만 종류/각도/직접 명중의 임시 문맥을 전달한다. 문맥은 try/finally로 복구한다. 지속 피해·보호막만 맞음·무효 대상·빗나감에는 직접 명중 모션을 만들지 않는다. 기존 피해 함수와 넉백 계산은 그대로 둔다.
3. GPU와 Canvas에서 같은 시각 파라미터를 한 번만 적용한다. 전격 반응이 활성일 때 새 가시·채찍의 신체 변형은 중첩하지 않는다. 화면 밖 효과는 그리지 않고 일반 다수 명중에는 합치기와 개수 제한을 둔다. 기존 총·칼 반응과 새 국소 효과를 합쳐 최대 48개 수준을 넘지 않도록 예산을 공유한다. 전격의 기존 별도 상한을 늘리지 않는다.
4. 기존 경고 범위의 그리기 순서를 보존하고 경고 위에 불투명 이펙트를 덮지 않는다. 모션 감소 설정에서는 몸 변형을 끄고 시각 수명과 발광을 줄인다. 파츠 그림을 확대하거나 다시 생성하지 않는다.

후보 파일명은 web/organ-hit-reactions-v613.js, web/organ-hit-adapter-v613.js, tools/package_organ_hits_v613.py, tests/organ_hits_v613.test.cjs 및 tests/organ_hits_browser_v613.cjs다. 최신 main이 달라졌다면 버전과 연결점을 먼저 재확인한다. 이 명세는 아직 이 파일들이 구현되었다는 의미가 아니다.

## 다음 구간의 검증 기준

- 실제 가시 투사체와 실제 채찍 휩쓸기에서 각각 다른 시각 반응이 나오는지 확인한다.
- 직접 명중과 DOT를 구분하고 보호막/무효 명중이 가짜 충격을 만들지 않는지 검사한다.
- 기준선과 동일 시드·조건에서 피해·체력·관통·재사용 시간·기존 밀치기 결과가 같아야 한다.
- 전격 연쇄·경직은 원래 결과와 같고 기존 총·칼 모듈은 8개 검사를 계속 통과해야 한다.
- 세로·가로·모션 감소·대량 명중·귀환/재시작·저장/재접속을 검사한다.
- 기존 이미지 바이트와 사용자 맵/충돌 JSON, 저장키/장비 ID를 보존한다.
