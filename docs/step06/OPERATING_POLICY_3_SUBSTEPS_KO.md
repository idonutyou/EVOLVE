# 앞으로의 작업 방식 — 한 STEP을 3회 구간으로 나눔

사용자 지시 1회에는 한 구간만 진행하고 끝낸다. 각 구간의 실제 파일·남은 작업·재개 위치를 원격에 저장한다. 사용자가 이어서 진행하라고 하면 다음 미완료 구간을 재개한다. 자동으로 다음 구간이나 다음 큰 STEP까지 연속 실행하지 않는다.

| 구간 | 범위 | 체크포인트 |
|---|---|---|
| 1/3 설계 | 최신 기준선 확인, 실제 연결 구조 확인, 구현 범위와 검증 기준 확정 | 10%, 20%, 30% |
| 2/3 구현 | 필요한 리소스·코드 반영, 국소 동작 검사, 후보 정리 | 40%, 50%, 60%, 70% |
| 3/3 검증·배포 | 회귀 검사, 공개 배포 및 실제 사이트 확인, 최종 복구본 | 80%, 90%, 100% |

10%마다 원격 저장 후 다시 내려받아 압축 무결성·전체 바이트·각 파일 SHA-256을 확인하고, 확인이 끝난 뒤 진행률과 파일 용량을 보고한다. 이전 백업을 지우지 않는다. 이미 완료한 큰 STEP의 번호를 다시 매기거나 과거 완료본을 새 작업으로 덮어쓰지 않는다. 각 구간의 범위가 길어지면 현재 구간의 안전한 체크포인트에서 종료하고 다음 호출에서 같은 구간을 이어간다.

이미지 렌더링 필요 여부는 해당 구간 시작 전에 안내한다. 새로운 렌더링이 실제로 필요해지면 제작 전에 종류·이유·기존 리소스 대체 가능 여부를 안내한다. 설계 구간 종료를 게임 기능 구현 완료나 공개 배포 완료로 보고하지 않는다.
