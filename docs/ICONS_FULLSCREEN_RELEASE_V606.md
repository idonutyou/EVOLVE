# EVOLVE WEB-39 — 아이콘·시작 질감·전체화면

버전: `V575-WEB-39-ICONS-FULLSCREEN`
빌드: `926bd029033701434bd0eae3028d618851361804bdde74eced498792324b0b9d`
기준: WEB-37 `caa0430a13595695ce896aac22a5732bb39eb2ef`.
배포 주소: https://idonutyou.github.io/EVOLVE/

이번 사용자의 최종 요청이 이전 WEB-38 프레임 교체 요청보다 우선한다.

- 하단 버튼 프레임, 높이, 문구, 선택 색상 및 가로 비중 1.6 동작을 보존했다.
- 문구 위 다섯 아이콘만 첨부 첫 이미지의 1번 줄 그림으로 교체했다. 원본 PNG는 재인코딩하지 않았다. SVG 창과 밝기 기반 알파 처리로 주변 사각 배경을 제거한다. 전투 아이콘의 위쪽 프레임 선은 제외한다.
- 전투 시작 버튼은 기존 외곽선·테두리·화살표를 보존하고 안쪽에만 같은 참조의 5번 전투 버튼에서 가져온 붉은 균열 질감과 따뜻한 빛을 표시한다.
- 설치형 웹앱의 manifest를 `fullscreen`으로 선언했다. 192/512 아이콘 및 maskable 아이콘을 제공한다.
- 기존 설정창에 전체화면·홈 화면에 설치 버튼을 추가했다. 안드로이드 브라우저의 전투 시작 클릭에서도 사용자 동작으로 전체화면을 요청한다. 실패해도 전투 시작은 계속된다.
- 기존 게임 실행 코드 전체, 하단 메뉴 CSS, 원본 게임 이미지 1,005개가 기준과 바이트 단위로 같다. 저장 키·업데이트 키·맵·몬스터·밸런스·무기·캐릭터 시작 크기는 보존했다.

## 휴대폰에서 실행

1. Chrome에서 https://idonutyou.github.io/EVOLVE/ 를 연다.
2. 새 버전 안내가 있으면 게임 홈에서 사용자가 업데이트 적용을 누른다.
3. Chrome 메뉴(⋮) → 홈 화면에 추가 → 설치를 선택한다.
4. 휴대폰 홈 화면의 EVOLVE 아이콘으로 실행한다.

설정창의 전체화면 버튼으로 브라우저에서도 진입·해제할 수 있다. 운영체제 제스처나 알림 패널을 열면 시스템 UI가 잠시 표시될 수 있다.

## 검증과 복구

로컬 메뉴·캐릭터 검사 6항목 및 전체화면 진입/해제·manifest·아이콘 크기·저장 유지 검사를 통과했다. 화면 크기 4종 × 메뉴 5상태의 20조합을 확인했다. 이 결과는 자동 브라우저 검사이며 실물 Galaxy S23+ 검사는 하지 않았다.

초기 배포 검사에서는 새 화면 스크립트를 `web-shell`로 분류하여 기존 시작 파일이 하나여야 한다는 검증이 중단했다. 분류를 `presentation-code`로 고쳤고 기존 lifecycle 스크립트와 검증은 보존했다. 정확히 같은 배포 전 검증을 로컬에서도 통과했다.
