# WEB-26 강화 카드 · 호드 · 몬스터 선택

기준: WEB-25 / `2fa4c431a76737486ed94e11016d605556c98c0a`.

## 요청한 동작

- 매 레벨 카드 3장 중 1장 선택. 카드 전체를 누른다. 별도의 선택 버튼이나 빈 버튼 테두리는 없다.
- 등급 → 여백 있는 그림 → 이름 → 수치 1~2줄 → 부위 순서. 한글 고딕은 Noto Sans KR의 필요한 글자만 묶어 제공하며 OFL을 스타일시트와 저장소에 포함한다.
- 최종 사용자가 고정한 매끈한 장비 외형을 유지하고 발광·번짐만 두 단계 강화한 새 아틀라스 사용. 커먼 무채색, 레어 파랑, 에픽 보라, 전설 노랑, 신화 주황. 신화는 정적인 광채에 더해 천천히 밝아지는 반짝임이 있다. 모션 감소 설정에서는 정적인 강한 빛으로 표시한다.
- 매 레벨 필요 경험치 **12**. 기존 1레벨 값이다. 레벨 제한 없이 초과 경험치와 획득한 강화 선택을 모두 보존한다.
- 일반 몬스터 등장 간격과 밀집 상한을 WEB-25보다 30% 증가한 물량으로 조정. 원래 기준의 등장 배율은 1.5 → 1.95. 정수 웨이브는 기존 올림 후 추가 30%를 올림한다. 기존 기기별 최대 개체 수, 절반 이동 속도, 공격 역할과 보스 증원 규칙은 유지한다.
- 관리자 모드 TEST에서 일반 8종, 기존 외형 변형 2종, 정예/네메시스 6종, 보스 7종을 선택한다. 총 23항목이다. 일반 1/10/50마리, 정예 1마리, 보스는 한 번에 1마리. BIO/VENOM은 기존 페이즈 선택과 정식 보스전 시작을 연결하고, 그 외 보스는 기존 시험 패턴을 이용한다.
- 명시적인 관리자 소환에 한해 스테이지의 몬스터 유형 제한과 자연 생성 끄기를 우회한다. 일반 플레이와 자연 생성 규칙은 우회하지 않는다. 선택한 외형 미리보기가 즉시 표시된다. 소환은 한 틱에 최대 3마리씩 처리하고 실제 충돌 지형을 검사한다.

## 누적과 실제 전투 처리

- 장비 카드로 고른 총·칼은 현재 전투에서만 교체한다. 홈의 저장된 ARM 장비는 바꾸지 않는다. 새 전투에서는 강화 누적도 초기화한다.
- 총 능력은 총을 사용할 때, 칼 능력은 칼 또는 기본 앞발 근접 공격을 사용할 때 적용한다. 총을 사용하는 동안 칼 스탯 카드, 칼을 사용하는 동안 총 스탯 카드는 추첨하지 않는다. 다른 장비로 바꾸는 장착 카드와 뒷발/외피 카드는 추첨 가능하다.
- 추가 탄환은 원래 탄환과 같은 기본 피해량이다. 관통을 먼저 사용하고, 관통이 소진되면 아직 맞지 않은 적을 향해 도탄한다. 같은 탄환은 같은 적을 반복해서 맞히지 않는다. 총에서 칼로 바꾼 뒤에도 이미 발사한 탄환과 폭발은 총의 공격력으로 처리하고 칼의 치명타·출혈을 적용하지 않는다. 벽 충돌은 그대로 적용한다.
- 공격력/공격 속도/범위/이동 속도의 증가분은 덧셈으로 누적한다. 이동 속도는 현재 전투의 기본 속도를 기준으로 더한다. 총의 연사 간격은 기존 간격을 증가한 속도로 나누며 최저 간격은 0.04초다. 칼은 휘두르는 모션과 판정 시간도 함께 빨라진다.
- 치명타는 2배 피해이며 확률 최대 100%. 끝에 남은 증가량만 카드에 표시하고 100%에서는 해당 카드를 추첨하지 않는다.
- 출혈은 현재 누적된 출혈 피해를 3초에 나누어 준다. 다시 베면 3초를 갱신하며 같은 대상에 무제한 중첩하지 않는다. 출혈로 다시 출혈을 발동시키지 않는다. 게임 일시정지/카드 선택 중에는 진행하지 않는다.
- 방어력은 기존 방어 처리 전에 수치만큼 피해를 줄이고, 양수 공격의 최소 피해는 1이다. 재생은 5초의 실제 게임 시간이 경과할 때마다 회복한다.
- 경량화의 두 이점은 등급 배율을 적용한다. 거대화의 체력만 배율을 적용하고 크기 불이익은 매번 +5%로 고정한다. 크기는 기본의 35%~200%이며 표시 크기와 실제 충돌 반경에 함께 적용한다. 상한/하한에서는 해당 크기 카드를 추첨하지 않는다. 끝에서 남은 크기 변화량은 카드에 정확하게 표시한다.
