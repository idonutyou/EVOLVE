# EVOLVE WEB-41 레벨업 화면 수정

공개 게임: https://idonutyou.github.io/EVOLVE/

붉은 생체 장식과 원본 레벨업 제목 프레임을 적용했다. 붉은 테두리 내부는 불투명하게 채우고, 바깥에는 멈춘 전장이 보이도록 했다. 중복 플레이어 레벨은 숨기고 기존 왼쪽 위 HUD를 사용한다. 다시 뽑기는 하단 중앙에 배치하고 제목과 같은 푸른 이미지 프레임으로 바꿨다. 프레임 바깥 여백을 두고 잘라내는 CSS를 제거했다.

시스템 바·화면 크기·전체화면·앱 복귀로 캔버스가 지워져도 강화 선택 중 전장을 다시 그린다. 게임 시간과 전투는 진행하지 않는다. 게임 코드 변경은 화면 이벤트 처리 1189바이트뿐이며 제거하면 기존 코드와 바이트 단위로 일치한다. 원본 이미지 1009개와 저장 키를 보존했다.

전체 브라우저 검사 23개, 공개 사이트 검사 5개, 공개 파일 7개 대조를 통과했다. 공개 사이트의 5가지 화면 크기에서 배경 유지, 시간 정지, 실제 카드 선택·다시 뽑기, 불투명 내부와 프레임 여백을 확인했다. 자동화 검사 결과이며 실제 Galaxy S23+ 기기 시험은 아니다.
