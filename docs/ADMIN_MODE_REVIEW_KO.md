기본 화면은 일반 게임이다. 처음에는 1스테이지·캐릭터 1레벨부터 플레이한다.

하단 **도감 버튼을 연속 5번** 누르면 현재 실행에서만 관리자 모드가 켜진다. 도감은 기존처럼 바로 열린다. 다른 하단 메뉴를 누르면 횟수를 다시 센다. TEST 창의 ‘관리자 모드 종료’로 일반 플레이로 돌아갈 수 있으며, 새로고침하면 관리자 기능은 다시 숨겨진다.

일반 화면에서는 TEST, 충돌 편집, 이동불가 표시, 맵 전체와 이전 진단 패널을 숨긴다. 저장된 테스트 맵·몬스터 자동 등장 설정은 일반 전투에 영향을 주지 않는다. 일반 플레이의 해금 기록은 개발자 스테이지 이동과 분리해 보관한다. 실제 1스테이지 승리로 2스테이지가 해금되는 동작을 검사했다.

이미지 986개, 모든 맵과 승인 충돌 데이터, 전투·보스·글씨, DNA·장비·기존 저장 키는 유지했다. 도감 버튼의 실제 클릭과 충돌 편집 도구, 저장·재진입, 세로·가로 화면 검사를 통과했다. 이는 자동 브라우저 검사이며 실제 Galaxy S23+ 실기 검사로 설명하지 않는다.
