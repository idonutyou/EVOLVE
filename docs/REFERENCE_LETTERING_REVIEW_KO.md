# WEB-17 · 제공 시안의 글씨 스타일 적용

요청: `1000027488.png`의 글씨로 교체.

은색 금속 질감과 녹색 하단 포인트의 BIO/VENOM TITAN 제목, 붉은 스텐실 WARNING, 두 줄의 CONTAINMENT BREACH, PHASE·COLOSSAL LIFEFORM 및 숫자 1·2·3을 투명 이미지로 교체했다. 제목과 헤더의 표시 높이를 조정해 제공 시안의 넓은 비율을 맞췄다. 붉은 WARNING이 읽히도록 경고 띠 가운데 배경만 어둡게 조정했다.

기존 문양, 보스 모션 프레임과 게임/지도/판정/저장 코드는 유지한다. WEB-16의 옅은 시전 전 범위 예고도 그대로다. 패키징 도구는 글씨 모듈과 경고 띠 배경 이외의 엔진 바이트가 기준 WEB-16과 일치하는지 검증한다. 기존 이미지 983개를 그대로 유지하고 기존 글씨 PNG 한 개만 새 PNG로 바꿨다. 글씨 이미지 파일은 2,357,319바이트에서 1,060,193바이트로 줄었다. 글씨 캐시는 1,256,968바이트이며 매 프레임 다시 만들지 않는다.

제작은 내장 이미지 편집 도구를 사용했다. 원본 시안은 `reference-lettering-v584.png`, 전체 프롬프트는 `reference-lettering-v584-image-prompts.json`, 사용 자산과 자르기 좌표는 `web/warning-branding-art-v581.json`에 있다.

실제 브라우저에서 투명도, 세로/가로 표시, 네 단계 등장 프레임, 일시 정지, 입력 잠금, 도착 무적 및 기존 보스 체력바 유지 검사를 수행했다. 마지막 띠 배경 변경 후에는 세로/가로 화면을 따로 확인했다. 물리 Galaxy S23+ 검사는 수행하지 않았다. 배포 시 기존 GitHub Actions의 전체 회귀 검사를 다시 통과해야 한다.
