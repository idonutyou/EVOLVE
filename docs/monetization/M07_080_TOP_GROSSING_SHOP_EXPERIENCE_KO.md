# EVOLVE M07 80% — 상위권 모바일게임 참고형 상점 실체험 구현
기준: 2026-10-28 KST · 사용자 지시 변경 반영 (이미지 제작은 상점 전용만 허용)

## 참고한 수익화 UX 구조
- 2025~2026 상위 매출 게임들(Honor of Kings, Whiteout Survival, Last War, Royal Match, MONOPOLY GO!, Brawl Stars 등)의 공통 쇼핑 패턴을 비교했다. 특정 게임의 상품 비주얼을 복제하지 않고, **추천/재화/한정 외형/시즌패스/패키지**와 첫 획득 보너스, 반복 구매 SKU, 데일리 연구, 무료/프리미엄 미션 트랙 같은 범용 패턴을 가져왔다.
- 참고 리서치: https://www.pocketgamer.biz/the-top-grossing-mobile-games-of-2025/ , https://mobilegamer.biz/2026s-top-10-grossing-mobile-games-so-far-honor-of-kings-whiteout-survival-lastwar-royal-match-pubg-mobile-more/ , https://resources-cdn.appfigures.com/industry-reports/appfigures-2025-mobile-game-trends-strategies-c.pdf , https://support.hoyoverse.com/hc/en-us/articles/50333903392153-How-does-the-First-Purchase-Bonus-work
- 매출순위와 시스템 선택의 상관성은 성과를 보장하지 않는다. 가격(예: ₩1,200 / ₩3,300 / ₩4,900 / ₩5,900)은 화면 구성을 위한 **미확정 후보 값**이다. 실제 결제 연결 전 provider 승인/현지화/소비자 정책 검증 필요.

## 구현 파일과 게임 연동
- `web/shop-experience-v621.js` 및 동등한 `dist/shop-experience-v621.js`: **별도 브라우저 로컬 상점 지갑/영수증**. 고객 결제 없음, 상품 수령 즉시 지속 저장, 재호출 idempotency, 첫 구매 결정 +50, 첫 진화 상품(결정 75), 결정 100/300, 공명 코어 소장, 유료 월간 패스 보유 기간.
- `web/shop-front-v621.js` 및 동등한 `dist/shop-front-v621.js`: 기존 HOME **단일 SHOP** 화면에 마운트되는 신규 상점 UI. 추천/재화/외형/시즌/패키지 내부 카테고리 5개와 상점 카드, 자세히 보고 구매확인/즉시 지급, 결정 잔고, '오늘의 연구 보급' 일일 수령, 월간 패스 프리미엄 5단계 보상, 구매 완료 메시지, 모바일 터치 44px. SVG/이미지 렌더링 없는 CSS 장식.
- `dist/index.html`: 기존 V620 로컬 상점 엔진의 script 뒤에 V621 2종을 로드. 기존 V620 UI만 숨기고 V620 로컬 코어 엔진/브리지는 그대로 둔다. 공명 코어 상품 구매 시 기존 V615 코스메틱 소장 기록과 V617 draw 브리지의 `dev_core_theme_01` 장착을 호출하여 **실제 게임 외형에 반영**한다.
- 이번 변경은 원본 전투/캐릭터/몬스터/맵/원본 이미지 1,021개/게임 저장/M03 경제 원장에는 수정 없음. 브라우저 로컬 상점 전용 `EVOLVE_SHOP_EXPERIENCE_V621_V1` 키만 추가. 과거 M06 아트 브랜치와 010~070 백업 모두 보전.

## 사용자 화면 표현과 안전
사용자 지시에 따라 상품 카드와 버튼에 '모의 구매/TEST 상품/무료 테스트' 등의 용어를 쓰지 않는다. 일반적인 '구매','구매 확정','보유 중','월간 패스 활성화'로 보이도록 했다.
하지만 실제 결제가 없다는 사실을 숨기지 않도록 **상점 상단 '결제 연결 전 체험 중 · 금액 청구 없음 · 표시 가격은 확정되지 않았습니다'** 및 확인창에 금액이 청구되지 않는다고 명시한다. 영수증, 앱스토어 계약, 카드 승인, 서버 권리를 주지 않는다.
시즌 패스는 KST 매월 1일 00:00~그달 말일(다음 달 1일 00:00 미포함), 매달 새로 획득/활성화. 자동 갱신 없음. 무료 이벤트는 별도 28일이 가능하다. 로컬 기기 시간에 기반한 체험 기간은 **운영 부정수급/과금 근거가 절대 아님**.
공명 코어 이외의 V621 결정·패스 등은 **별도의 상점/시즌 체험 잔고**이며 원래 게임 DNA나 구매자 서버 월렛을 변경하지 않는다. 전투 성장에 무심코 연결하지 말 것. 프리미엄 보상은 매일 수령으로 순차 진행 가능하지만 실제 전투 진척 증명은 미구현이다.

## 보수적 오프라인 복구
V621 별도 저장소 손상 감지 시 데이터 삭제/초기화 불가, 해당 V621 UI 마운트 포기 후 기존 V620 UI 그대로 사용. 테스트 데이터와 M03 서버 권위/정식 거래 원장 서로 교차 이관 금지.
실제 가격 승인/서버 검증/환불/복원·월말 구매 공정성은 계속 M08 출시 차단.
