## 1. 구매할 이유가 분명한 '완제품'을 먼저
M06의 **첫 번째 판매 후보**는 `m06_core_reactor_concept`, 임시 상품명 **반응로 코어(REACTOR CORE)**다. `appearance_unlock_01`은 이미 쓰는 개발 TEST '공명 코어' 권리와 연결되어 있다. 이를 덮어쓰거나 TEST 구매를 유료 권리로 자동 이전하지 않는다. 실제 출시 SKU/가격/영구소유 계약은 **콘텐츠 완성·M08 운영 결제 검증 전 미확정**이다.

구매자가 돈을 낼 만한 차별성은 *청록→주황 단순 색 교체*가 아니라, **육각 외부 보호 케이싱 + 어긋난 이중 궤도 링 + 조각난 중심 렌즈 + 별도 잔광**을 하나의 아이덴티티로 소유하는 것이다. 현재 공명/심홍은 모두 타원 핵과 좌우 방사선 형태이므로 실루엣만으로 구분돼야 한다. 색을 모두 제거해도 선택 화면에서 코어 3개 중 반응로가 구분되지 않으면 출시 불합격이다.

## 2. 실제 기존 엔진과의 정합성
- V617 기존 코어 렌더러는 **192×192 Canvas 텍스처 2개**를 캐시한다(192×192×4×2=294,912B). 세 번째 테마를 같은 크기로 만든다면 **총 442,368B**가 텍스처만의 이론적 RGBA 상한이다. 실제 그래픽 메모리/합성 비용은 별도 측정이 필요하다.
- 지금 레이어는 `mutantArtV599.shell` 기준점을 통해 PARTS 미리보기와 전투 `drawPlayer` 오버레이에 표시된다. 본 디자인은 그 **core 외형 슬롯과 위치 원칙을 재사용**하며 플레이어 원본/맵/공격 판정은 변경하지 않는다. SHOP에서 상품별 별도 미리보기 연동은 후속 구현 항목이다.
- 계획된 구조: 배경 캐릭터 → 바깥 육각 케이싱 → 렌즈 → 전면 궤도 링 → 선택 잔광. 원본 플레이어 이미지가 아닌 **투명한 개별 레이어**로 구분해야 한다. 각 레이어 공통 피벗(192 기준 96,96), 안전 여백 최소 16px 제안. 레이어/파일 이름은 임시이며 30%에 동결한다.
- 전투 중 신규 Canvas 생성, 프레임당 storage 접근, DOM 갱신, 새 타이머 무한 생성 금지. 저사양에서 시각 효과를 끌 수 있게 준비.

## 4. 상태/소유권: 팔 수 있기 전과 후는 별개
**현재 상태:** `COMING_SOON → PREVIEW → 취소`만 허용한다는 기획. PREVIEW는 화면에 합성한 모습만 보여주며 저장·권리를 변경하지 않는다. **M08 이전 실제 구매 클릭은 결제 불가로 차단**한다. 지금 SHOP의 TEST 구매 엔진은 그대로이며 위 상태 기획이 아직 앱에 붙은 것은 아니다.

**미래 M08 상태:** `AVAILABLE → PENDING_SERVER_RECEIPT → (검증 성공) OWNED → EQUIPPED ↔ UNEQUIPPED`. 검증 중/실패는 `OWNERSHIP_UNVERIFIED`, 서버가 환불/취소를 확정한 **해당 구매 출처**의 권리는 `REVOKED_OR_REFUNDED`. 저장 오류나 통신 실패로 유료 권리를 임의 삭제해서는 안 된다. 여러 구매 경로가 있을 때 다른 정상 소유권까지 제거하지 않는다.

실제 금전 구매는 상점 플랫폼과 서버 원장·검증된 영수증만이 최종 지급할 수 있다. `EVOLVE_DEV_MOCK_STORE_V1` / `EVOLVE_V575_TEST_*` / 무료 DNA / 운영 원장은 서로 섞지 않는다. 같은 요청 반복에 재지급·중복 차감 금지, 미보유·환불 권리 장착 금지.
