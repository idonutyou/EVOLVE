## 적용 사항

1. **손상된 테스트 저장(localStorage) FAIL CLOSED**: 새 UI를 열 때 기존 M04 모의 스토어 snapshot을 읽을 수 없으면 구매 UI를 열지 않고 `role=alert` 오류 모달로 대체한다. '닫기'만 가능. 원래 손상 바이트를 삭제하거나 수정하지 않는다. M04의 정상 URL에는 영향을 주지 않는다.
2. **TEST 구매 저장 실패**: 정상 화면 내 구매 확인에서 localStorage 쓰기가 실패하면 모의 구매 추가 실행·코어 장착·초기화·재확인을 막고 읽기 전용 배너를 보여 준다. 실패 후에는 현재 화면에서 자동 재시도하지 않는다. 결제 성공이라 오인하지 않도록 기존 M04 오류를 함께 표시한다.
3. **확인창 열림 중 이동 경합 차단**: 상품 상세 뒤로가기/컬렉션 탭/바로가기 등은 확인창이 있는 동안 동작하지 않는다.
4. **확인창 닫기 우선순위**: 구매 확인 중 모달 바깥 배경을 누르거나 상단 닫기를 누르면 즉시 모달 전체를 닫지 않고 **구매 확인만 취소**한다. 확인창의 '취소'와 동일하게 저장값 유지. 게임 화면 복귀 여부는 확인 취소 이후에 결정할 수 있다.
5. **빠른 다중 터치·중복 확인**: 기존 M04 멱등 구매 엔진을 그대로 사용. 확인 버튼 3회 연속 이벤트에도 TEST 결정 100개만 지급.
6. **안전한 스토어 저장 경계**: UI 레이어가 실제 결제/영수증 데이터를 만들지 않고 `EVOLVE_DEV_MOCK_STORE_V1`에 대한 M04 함수를 호출·표시만 한다. 기존 게임 저장 `EVOLVE_V575_TEST_*`, DNA, 파츠, 스테이지, 전투 성능은 변경하지 않는다.
