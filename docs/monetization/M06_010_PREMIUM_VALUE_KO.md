## 0. 가장 중요한 결정
수익화의 1순위는 **실제 돈을 지불할 만큼 구별되는 콘텐츠**이다. 가격표·결제 버튼부터 만드는 것이 아니라, 일반 플레이만으로는 얻기 어려운 '소유하고 계속 장착하고 싶은 외형'을 검증한다. 현재 V620 **기존 홈 SHOP 하나만** 사용하며 DEV 상점/팝업을 되살리지 않는다. 테스트 구매는 실제 결제가 아니며 기존 5 SKU 모두 정식 가격 null, checkout/운영 권리 지급 OFF다. Google Play/Apple 실결제는 게임 전체 완성 후 M08.

## 2. EVOLVE 전용 아트 고정 규칙
- 기본 진화체와 기존 1,021개 원본 이미지는 바꾸거나 재압축하지 않는다. 유료 외형은 명시적으로 분리된 오버레이/리소스로만 제작·교체한다.
- 코어: 작은 모바일 화면에서도 크기·실루엣·박동 주기·잔광 패턴이 서로 달라야 한다. **색만 바꾸는 프리미엄 품질 금지**.
- 앞발 생체무장: 1구멍짜리 총열, 좌/우 **2개 부품**. 가시·꼬리·수동 장식처럼 보이지 않아야 하며, 각 앞발과 분리된 교체 가능한 파츠여야 한다. 3구멍 다연장 총열 금지.
- 머리/몸/앞발/뒷발/꼬리/코어 슬롯 간 고정점을 별도로 정의하고 서로 얽힌 통짜 이미지 금지. 생물학적 형상을 유지하되 총/칼은 무기로 즉시 인식되는 디자인.
- 공격 이펙트는 가시성 확보. 소액 결제자·무과금자 모두 적 판정/경고를 가리지 않게 광량/크기를 제한한다.
- 무료 획득 가능한 외형은 충분히 유지, 유료 랜덤 뽑기/능력치 우위/전투 중 강제 구매 팝업 금지.

## 3. 상점에서 판매로 연결하는 최소 UX
기본 `SHOP`에서 **미리보기 → 실제 구성/장착 슬롯 공개 → 보유 여부 → 영구 소유/복원 조건 → 구매 또는 안전한 취소 → 장착** 순서를 보장한다. 미제작 제품은 '준비 중'으로만 표기하고 결제 CTA/가격/실제 판매를 열지 않는다. 테스트 결정 `EVOLVE_DEV_MOCK_STORE_V1`은 본편 `EVOLVE_V575_TEST_*` 세이브, 무료 DNA, 운영 원장과 절대 합치지 않는다.

기획 가격/보상 가정은 M02 문서에만 있으며 실제 통화 가격은 운영 SKU가 허용될 때까지 `null`이다. 기존 5개 SKU는 식별자·잠금 상태 불변. 특히 시즌 패스는 잠금. 소유권·환불·복원은 서버 검증 전까지 진짜 유료 권리를 부여할 수 없다.

## 4. 10% 완료 검수 계약
1. 판매해야 하는 이유 4개 후보의 차별성·순위·슬롯·기존 SKU와의 관계가 서술되어 있을 것.
2. P0는 현재 공명/심홍 테스트 코어와 다른 조형·패턴을 갖는 기획일 것.
3. P1은 반드시 양쪽 앞발의 **분리 가능한 단일 총구 생체포 2개**일 것.
4. 현재 SHOP 단일화·DEV UI 삭제 및 기존 1,021 원본 이미지/게임 엔진·세이브 유지.
5. 가격 null, 결제 OFF, 운영 권리 OFF, 이 단계 이미지는 생성하지 않음.
6. 10% 원격 전체 트리 복구 branch + 증분 아카이브·체크섬을 보관하고 원격에서 독립 2회 확인.
