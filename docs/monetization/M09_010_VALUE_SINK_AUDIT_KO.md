# EVOLVE M09 — 10% 현재 수익화 가치·소비처 실사
작성: 2026-10-29 KST · 상태: M09 10% 설계/분석 완료 · 이미지 렌더링: 불필요

## 목표와 범위
이 M09는 **수익화 확장 단계**이며 과거 43단계 로드맵의 'STEP09 진화 수집'과 다른 작업이다.
게임의 SHOP·CHALLENGE·수익화 흐름을 실제 파일에서 감사했으며, 이 문서 단계에서는 구매·재화·캐릭터·맵·이미지·기존 세이브·배포 파일을 일절 수정하지 않는다.
사용자 우선순위: 과금 요소 및 상품의 실제 사용 가치가 1순위. 실제 카드 청구만 연결하지 않고 상점에서는 실제처럼 상품을 획득·착용할 수 있게 한다. 안내 문구로 실제 청구 없음은 명확히 유지.

- 일일 스테이지/도감 달성은 실제 진행 상황에 따라 **항상 완료할 수 있는 보상이 아님**. 이 상한을 실유저 평균 수입으로 쓰면 안 된다.
- 현재 확인되는 결정 소모처는 심홍 코어 **120결정, 영구 1회**. 누적 무료 최대 45/일일 경우 이론상 3일이면 도달. 이후 반복 소모처가 빈약함.
- 유료 월간 패스 최대 보상은 +175결정(5×35), 달성 조건은 누적 무료 보급 수령일 1~5일; 한 달 전체를 아우르는 차별화된 반복 가치가 약함.
- 결제 금액은 화면상 후보 가격일 뿐 **실제로는 청구되지 않으며**, 로컬 요청은 `charged:false`, `GRANTED_LOCAL`로 기록됨.

## 사업·기술 위험도 판정
P0: 결정 획득 > 실용 소모처 — 유료 결정을 살 이유가 부족함. 먼저 지갑 소비처와 수집 가치 마련.
P0: 새 코어/파츠 이미지를 별도 채팅방에서 재설계 중. 기존 공명/심홍 외형 기반으로 새 캐릭터에 종속되는 유료 아트·착용을 설계하면 재작업 발생. 새로운 캐릭터 이미지 제작은 이 M09 설계에서 금지.
P0: `localStorage` 증거/지갑 및 월간 패스는 클라이언트 수정이 가능하므로 *실제 유료 권리*가 될 수 없음. 향후 실결제는 서버 영수증 원장·환불·기기 복원과 독립해야 함.
P1: 첫 구매 제안 가치와 연구 패스가 실제 유저에게 검증된 지표 없음. 경제 시뮬레이션·누적 보상 명확화·게임방해 없는 노출이 선행.
P1: 사용자 정책 — **유료 기간제는 KST 해당 월 1일~말일**, 자동 갱신 없음. 무료 이벤트에 한해 28일 운영 가능.
P2: 실제 광고 공급자, 운영 결제, 트래킹/개인정보 승인 없이 '실매출'이나 '구매전환율' 주장 불가.
