상위권 게임의 저작물·정확한 스토어 화면·이미지 복제가 아니라, 시즌·외형의 지속 소유 가치와 일일 참여·상점 재화 사용처·수령 표시 등 범용 구조를 EVOLVE에 적용한다.

## 이번에 실제로 구현한 것
1. SHOP **공명 코어 / 심홍 코어 2종 컬렉션**과 장착·해제 버튼. 첫 상품 획득에 더해 브라우저에 이미 소유한 코어도 읽어서 인벤토리 상태에 표시한다.
2. **결정 소비처 실작동**: 변이 결정 120개로 심홍 코어 영구 교환. 동일 요청 재생은 한 번만 처리, 부족하면 차단, 소유권/잔고는 새로고침 후 유지. 결정 사용은 최초 유료 상품 구매 보너스 판정과 분리한다.
3. **기존 게임 코어 그래픽 엔진 V617 활용**: V621 상품과 기존 V615/V617 외형 보유·장착 데이터를 연결한다. 공명/심홍 코어를 장착하면 원래 전투 캐릭터의 **이미 존재하던 두 외형의 표시만 전환**된다. 게임 전투, 몬스터, 코어 다리/형태 신규 렌더링 코드를 변경하지 않았다.
4. **기존 HOME CHALLENGE 탭 연구 시즌 패널**: 원래 스테이지 카드·기록은 그대로 두고 별도 블록을 추가한다. 매일 한 번 무료 연구 보급, 프리미엄 보유 시 연구 단계 1~5의 결정 보상, 수령 완료/출석 진행/월간 만료 표시, 패스가 없으면 기존 SHOP 시즌 카테고리로 이동.
5. **코어 복원성**: V621 지갑과 V615 코어 보유 상태는 각각 로컬 저장소이므로 상호 DB 트랜잭션은 없음. 상품 교환이 V621에 먼저 저장되고 V615 외형 연결 실패 시 다음 코어 장착 클릭으로 시도하는 **재연결 가능 동작**을 구현했다. 여전히 미지급/실결제 영수증·서버 계정 권위는 없음. 운영 결제 연결 전 원장 통합·동기화 검증은 필수.
6. 기존 HOME SHOP 그대로, 개발자 전용 상점 없음, 쇼핑 UI 실제 버튼은 '구매·교환·장착·해제·수령'로 노출. 사용자가 비용이 청구된 것으로 오해하지 않도록 **결제 연결 전 체험 중 · 실제 금액 청구 없음 · 표시 가격 미확정**이 상단·확인창에 표시된다. 결제 SDK나 PG 통신, 카드 승인 없음.

## 월간 유료/무료 구분
- 유료 월간 연구 패스: **한국시간 매월 1일 00:00부터 그달 마지막날 23:59:59**, 다음달 1일 00:00 이후 기간 종료. 28/29/30/31일 모두 검사, 자동결제/자동갱신 없음.
- 무료 이벤트: 별도 28일 주기 허용; 월간 패스와 동기화 강제 금지. 현재 CHALLENGE의 '일일 연구 보급'은 실제 게임 런 완료/도감 발견 증거와 연결하지 않은 **출석/무료 수령 콘텐츠**이다. 기존 M07 70%의 run/stage/codex 가상 미션이 실제로 서버 인증 진행하는 것으로 주장하지 않는다.
- 영구 구매·교환된 코어 외형은 유료 패스 월말 종료로 삭제하지 않는다.
