이벤트는 `(seasonId, accountId, missionId, eventId)`로 중복 제거하고, 완료는 `(seasonId, accountId, missionId, periodKey)`, 지급은 `(seasonId, accountId, rewardId)`로 유일화하는 계약이다. 모든 인증은 **향후 서버 권위 모델의 필요조건**이고, 브라우저가 신뢰 플래그를 단순 전달하면 곧바로 실제 보상을 지급하는 방식은 금지한다.

## 3. 일/주 경계, 28일 시즌 제안
- 모든 실제 보상 판단은 미래 **서버에서 인증한 UTC 기준**. 일일 기준은 UTC 00:00, 주간 기준은 월요일 UTC 00:00. 한국에서는 오전 9시에 날짜가 바뀌는 UI로 설명할 필요가 있다.
- 최초 시즌 시작은 서버가 확정한 UTC 자정에만 가능, 28일은 **기획 가정**이고 실제 운영일은 미확정. 테스트 예: 2026-10-28T00:00:00.000Z 시작 → 2026-11-25T00:00:00.000Z 종료(종료 시점은 제외).
- 제안 상한: **일일 두 미션 각각 하루 1번 + 주간 한 미션 매 UTC 주 1번**, 미션당 1 연구 포인트(시안). 예시 시즌은 UTC 일 28개, 교차하는 월요일 기준 주 5개이므로 **이론상 최대 무료 포인트 2×28+5=61**. 한국시간으로 임의 재설정할 수 없고, 다른 시즌 시작일이면 교차하는 주의 수가 달라진다.
- **61은 정식 재화나 구매 가능한 결정의 지급량이 아니다.** 실제 보상 지급 0, 권리 지급 0, DNA 지급 0으로 유지. 시즌 활성화/실화폐 가격 미정.
- 플레이어가 시간을 바꾸거나 오프라인에서 완료 기록을 제출해도 검증 전에는 '미확인'으로 처리한다. 유효 이벤트가 아니라면 이중 보상·무한 반복·지난 시즌 이월 금지.
