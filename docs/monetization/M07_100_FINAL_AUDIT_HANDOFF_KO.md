# EVOLVE M07 100% — 상점/시즌패스 체험형 시스템 최종 검수 및 M08 인수인계
작성일: 2026-10-28 KST · 범위: 쇼핑 UI와 게임 안 로컬 체험 · 실결제 제외

## 사용자 확정 정책
1. **매출 상위권 모바일 게임의 구조를 참고하되 저작물 직접 복제 금지**: 추천 배너, 재화/패키지/외형, 월간 시즌 패스, 첫 구매 혜택, 일일 보급과 시즌 프리미엄 보상을 한 개의 기존 SHOP 및 CHALLENGE에 연결한다.
2. 실제 결제 SDK·카드 청구·영수증 검증은 **미연결**. 구매 버튼은 실제로 눌러서 브라우저의 별도 체험 재화/외형/패스 보유를 즉시 받는다. 화면 버튼 이름은 구매·교환·보유·수령·장착이며 '모의 구매/TEST 상품' 등의 표기를 사용하지 않는다. 하지만 돈이 청구되지 않는다는 **명확한 안내**는 상점/확인 화면에서 반드시 유지한다.
3. **유료 기간제 상품은 해당 달 1일~말일까지 KST**. 다음 달 1일 00:00부터 전월 권리는 만료되며 자동 갱신은 없음. 무료 미션/이벤트는 별도의 28일 운영도 허용. 영구 소유한 코어 외형은 월말과 무관하게 보존한다.
4. 전투/캐릭터/몬스터/맵/원본 이미지 1,021개는 이번 M07에서 변경하지 않는다. 기존 V615·V617 외형 브리지와 기존 HOME 다섯 탭 및 SHOP 한 개만 활용한다. 상점 이미지/배너는 향후 렌더링 허용, 전투/생물 이미지 렌더링은 후순위.

## M07 80~100 실제 작동 기능
- 게임 HOME SHOP: 5개 내부 상품 카테고리(추천/재화/외형/시즌/패키지), 유료 가격 후보를 표기하되 청구 없이 즉시 수령, 변이 결정 로컬 지갑·첫 구매 결정+50·결정100/300 묶음.
- 코어 외형: 기존 공명 코어 구매 및 장착, 변이 결정 **120개 소모해 심홍 코어 영구 획득**, 두 코어 컬렉션에서 장착/해제 가능(기존 V617 전투 코어 그래픽에 반영, 본체·몬스터·전투 시스템 자체 수정 없음).
- CHALLENGE 탭: 기존 스테이지 도전 카드 보존 아래 무료 일일 연구 보급(+20결정), 월간 프리미엄 1~5단계 출석 보상(단계당 +35결정), 완료/진행 상태와 SHOP 이동. 프리미엄 패스는 획득한 해당 월에만 활성화되고 종료 즉시 비활성화.
- 새로고침 후 브라우저 저장키 `EVOLVE_SHOP_EXPERIENCE_V621_V1`에서 지갑·보유권·월간 기록·일일 수령 복원. 원래 게임 세이브/M03 경제 원장과 완전히 분리. 저장 데이터 손상 시 임의 초기화/손실 방지.
- V621 100 수정: 오래된 구매 요청이 **10월→11월을 가로질러 재전송**되어도 중복 지급이나 11월 패스 해금을 하지 않고 전월 동일 영수증 재표시. 월말 24시간 미만 시 구매 확인화면에 경고와 해당 월 남은 기간 표시. 외부 결제 사용 없음.
- `dist/index.html`의 V621 스크립트에 `?v=100` 캐시 갱신, `tools/wait_for_shop_publication.py`에서 **실제 공개 Pages index/script가 V100인지** 확인한 다음 라이브 회귀 검사 진행.

## 현재 기능의 한계 (M08로 명시 이관)
- '변이 결정'은 V621 **브라우저 체험 지갑**이지 실제 DNA/서버 계정 재화가 아니다. 실제 게임 전투 결과에 따른 RUN/STAGE/CODEX 인증 이벤트 자동 진행은 미연결. 현재 CHALLENGE는 일일 보급·출석 기반이며 '실제 전투를 클리어하면 미션 완료'를 제공하지 않는다.
- 앱 삭제·브라우저 데이터 삭제·기기 변경 시 권리 복원 불가. 멀티 탭 동시성 및 클라이언트 시계 조작은 서버 원장 없이는 안전성을 보장할 수 없다.
- 외부 실제 결제 연결을 시작하면 공급자 영수증 서버 검증, 계정 소유권, 환불·복원, 패스 월말 구매 공정성(잔여기간/소급 보상), 승인 가격, 국가별 법규, 부모 보호 관련 조치가 필수다.
- 유료로 구매한 것처럼 보이는 것은 체험 UX지만 **'실제 청구 없음'을 숨기거나 실제 결제처럼 증명하지 않는다**.
- 기존 구매 토큰/로컬 UI 체험값을 미래 운영 서버의 유료 영수증으로 승인하거나 이관하지 않는다.
