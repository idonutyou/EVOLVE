# EVOLVE — M07 30% STEP 1/3 최종 설계 동결
기준일: 2026-10-28 KST · 프로그램 진행률은 M07 설계 구간에 대한 수치이며 게임/출시 완료율이 아니다.

## 1. 사용자 기간 정책 (최우선)
**기간 제한형 유료 시즌 패스는 무조건 매월 1일 00:00부터 해당 월 말일까지(한국시간).** 종료 연산은 다음 달 1일 00:00 KST 미포함. 28·29·30·31일을 달력대로 지원. 구매일부터 28일짜리 유료 상품, 28일이 되면 유료 시즌 종료되는 정책은 금지한다.

**무료·무과금 이벤트는 별도 28일 운영 가능.** M07 10~20%의 28일 연구 포인트 계산은 무료 이벤트 시안이고 유료 시즌패스 만료일이 아니다. 무료 이벤트가 끝나도 유료 월간 보유는 달력 말일까지 유지되어야 하며, 유료 시즌 만료가 무료 이벤트 기록을 지워서도 안 된다. 영구 구매 외형은 기간 종료로 삭제되지 않는다.

권위 원본: `monetization/m07/monthly-calendar-policy.v1.json`. 기간 계산: `paid-month-calendar-v1.cjs`(유료 KST), `utc-period-planner-v1.cjs`(무료 28일 후보).

## 2. 시즌/미션 API 계약 — 설계 전용
`monetization/m07/season-api-contract-030.v1.json`은 M08 이후 필요한 읽기/쓰기 API의 형태만 정의한다. **현재 서버 URL·계정 서버·검증 이벤트 생산기·결제 백엔드가 연결된 것은 아니다.**

읽기 후보:
- `GET /v1/seasons/current`: 서버 기준시각, 무료 이벤트 기간, 유료 월간 기간·정확한 종료일·남은 시간·판매 여부.
- `GET /v1/seasons/{periodId}/missions`: 검증 완료 진행/검증 전 기록/보상 수령 가능 상태. 단순 HOME 버튼 누름은 완료로 인정하지 않음.
- `GET /v1/account/season-entitlements`: 계정 소유권과 월 단위 서버 영수증 상태.
- `GET /v1/seasons/history`: 이전 시즌 이력과 영구 획득 아이템.

쓰기 후보(전부 **미구현**):
- `POST /internal/v1/verified-play-events`: 오직 신뢰 가능한 게임 서버가 실제 종료·스테이지·도감 신규 해금 증거와 이벤트 ID를 전달. 프런트엔드가 `verified:true`라 주장해도 권리 없음.
- `POST /v1/seasons/{periodId}/claims`: 계정 인증·실제 서버 검증·중복키·보상 준비 완료 확인 후 서버에서만 원자적으로 지급.
- `POST /internal/v1/payment-entitlement-events`: **M08에서만** 승인된 거래처의 영수증 검증/환불/복원 처리. 영수증 없이 클라이언트가 직접 소유/보상을 변경할 수 없음.

검증 이벤트 중복키 `period_id+account_id+mission_id+event_id`, 보상 수령 중복키 `period_id+account_id+reward_id`. 불완전/손상/과거 스냅샷은 확인 보류하며 기존 게임 저장을 삭제하지 않는다.

## 3. 무료와 유료 상태 분리
무료 미션은 `ACTIVE → PENDING_UNVERIFIED → VERIFIED_COMPLETE → CLAIMABLE → CLAIMED` 방향이며, 오프라인/클라이언트 자체 기록만으로는 **보상 수령 가능으로 이동할 수 없다**.
유료 월간 패스는 `DRAFT_DISABLED → ART_PENDING → SALE_BLOCKED → AVAILABLE_AFTER_M08 → VERIFYING → OWNED_ACTIVE_MONTH → EXPIRED_MONTH`가 계획 상태다. 현재는 `DRAFT_DISABLED`이고 판매 준비가 되었다는 의미가 아니다.
영구 스킨 소유권과 지난달 기간제 패스는 별도 항목으로 보존. 유료 자동연장은 설정하지 않는다.

구체적 상태: `monetization/m07/season-states-release-gates-030.v1.json`, `season-state-transitions-030.v1.json`.

## 4. 수익화·구매자 공정성
M07의 핵심은 무료 이용자의 재방문과, 이후 확정될 **유료 코스메틱 수집 가치**다. 전투 대미지/스탯/성장 자체를 과금 전용으로 만들지 않는다.
유료 패스가 실제로 활성화될 경우 월말 구매에 대한 가격·소급 보상·구매 제한·남은 일수 안내가 반드시 승인되어야 한다. 현재 이 정책은 **미결정**이므로 후속 조건이 충족되어도 판매는 차단한다.
미완성 이미지/코어를 영구 보상이라고 속여서 결제 받지 않는다. `season_research_pass_01`는 계속 `draft_disabled`, 가격 `null`, 실제 체크아웃·클라이언트 지급 `false`.
