## 2. 추가 실제 코드 감사에서 발견한 유효한 연결 후보

3. `web/admin-state-v585.js`: `EVOLVE_V575_TEST_NORMAL_PROGRESS_V585` 키로 일반 진행도를 `localStorage`에 저장한다. 클라이언트 조작 가능하므로 시즌 보상·결제 권한 근거로 쓰지 않는다.
4. 기존 `web/home-hub-v601.js`: CODEX 메뉴 탭은 **화면 열기**일 뿐 신규 도감 **발견**의 검증 증거가 아니다.
