# EVOLVE M03 60% — 권리·환불 보안 경계 구현 (2026-10-27)

**범위:** 개발용 소스 구현. 실제 계정 공급자·결제사·DB 인프라 연동은 아직 없으며, 운영에서 구매 불가. 이미지 렌더링 불필요.

- `m03-server/rights.cjs`: 동일 외형을 다수 source로 소유하는 경우 active source를 서버에서 집계. 환불 요청은 사용자 인증을 마친 내부 시스템 호출에서만 pending_review로 기록. 유료 권리 회수, 음수 잔고 설정, 결제 승인 등은 구현하지 않음.
- `m03-server/tests/rights.test.cjs`: 서로 다른 원천 중 하나만 revoked일 때 다른 active 원천 유지, 환불 케이스 중복 방지, 잘못된 account 식별자 차단.
- `m03-server/tests/auth.test.cjs`: 짧은 수명 RS256 공개키 검증, 위조/만료/잘못된 issuer·audience 거부, 인증 설정 미존재 시 닫힌 상태 유지.
- 공개 API에서는 모든 POST 결제·재화 지급 경로가 여전히 503. `localStorage`의 무료 DNA를 지급 출처로 수용하는 기능 없음.
- 기존 M01 메모리 QA 원장의 독립 구매 source 소실 가능성을 실제 시스템으로 복제하지 않도록 회수 기능은 우선 잠금. M04에서 제공자 영수증/취소를 인증한 후에만 출처별 회수 설계/테스트를 진행해야 함.

**검증 주의:** 소스·테스트 파일이 있다고 해서 외부 인증 공급자 운영, 실제 DB 권리 복원·환불 무결성, 동시 환불 검증 완료를 뜻하지 않는다. 다음 70%에서 개발 환경의 가능한 테스트와 미실행인 실제 PostgreSQL 테스트를 정확하게 나누어 기록한다.
