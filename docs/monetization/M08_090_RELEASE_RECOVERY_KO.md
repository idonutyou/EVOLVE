# M08 90% — 출시 전 복구 및 통합 검사

- 60% 지점 이후 70% 모바일 오류 안내·키보드/스크린리더 편의성, 80% 보상/SHOP 브라우저 통합 변경을 SHA-256/CRC32 증분 ZIP으로 보존.
- 원본 게임·맵·전투·몬스터·이미지·V575 세이브는 변경하지 않음.
- SHOP V621 기존 저장값과 미션 기록을 유지, 일일 10+5+10 로컬 체험 결정을 사용. 서버 영수증 또는 진짜 결제는 없음.
- M08 10~80 계약, M07 월간 패스·영구 코어 체험 지갑 회귀, 원본 게임 DOM 브라우저(320/393/852px) 검증.
- 소스의 `web/` 및 `dist/` 복사본 일치, HTML M08 로딩 순서와 원본 게임 버전 파일 존재 확인.
- 체크포인트 ZIP은 **M08 60% 이후 변경 파일**만 포함. 전체 프로젝트 복구는 `backup/monetization-m08-090-20261029` 원격 Git 브랜치 사용.
- SHA256·CRC·크기·Git 작업트리 일치 검사를 CI로 시행. 과거 ZIP과 백업은 삭제하지 않음.
- 90% 완료 뒤 100% 단계에서는 `main`을 최신 검증 브랜치로 fast-forward한 뒤 기존 GitHub Pages 퍼블리시 워크플로 검증. 우선 별도 `backup/monetization-m08-100-predeploy-20261029` 백업으로 공개 서비스 롤백 가능하도록 할 것.
- 실제 Pages 배포 완료 및 CDN에 새 미션 JS/인덱스가 노출되었는지 별도로 확인. 게시 전 성공이라 보고하지 않음.
