- Node 20+ 개발 전용 `m03-server` 원장 API. 기본 실행 차단(`NODE_ENV=development` 및 별도 실행 플래그 필요), localhost 바인딩. 모든 구매·광고/클라이언트 임의 지급 API는 503 비활성.
- 외부에서 서명된 RS256 토큰의 형식/시간/발급자·대상 검증(정적 공개키 시험 전용). 실제 운영 OIDC/JWKS 키 회전·세션 폐기 프로세스는 미구현.
- POST 계정 bootstrap만 생성 가능. GET wallet/entitlements는 인증된 기존 계정 조회만 허용. 다른 계정의 식별자를 쿼리에 넣어 유료 재화 조회하도록 설계하지 않음.
- PostgreSQL 계정·무료/유료 mutation_crystal 지갑 분리, append-only 원장, 원자적 지출, 계정별 중복 키/요청 해시, 권리 출처별 보존, 환불 요청 수동 검토.
