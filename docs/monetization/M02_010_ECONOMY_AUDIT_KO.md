## 1. 기존 DNA 흐름

- 시작값: 새 저장은 DNA 0. `EVOLVE_V575_TEST_META_V1`에 DNA와 연구 레벨 등 저장. `loadMeta`는 해당 키를 읽고 `saveMeta`는 저장한다(122–124행).
- 기존 저장 내보내기/가져오기는 META JSON을 복사/붙여넣는 방식, 초기화는 2회 확인 후 해당 META 키 삭제(1296–1298행). 기기 간 동기화나 위변조 저항을 뜻하지 않는다.
- 플레이 시작 시 `dnaTotal=0`; 처치·이벤트 보상은 전투 중 이 값에 쌓인다(1087행). `finish`에서 `floor(dnaTotal) + objectiveBankBonus + performanceBankReward`를 0 이상으로 보정하여 DNA에 추가하고 `bankedThisRun`으로 같은 실행 내 중복 정산을 막는다(5578행). 패배해도 finish를 호출하며 성과 보너스에 별도 감산이 적용된다(5537, 2945–2955행).
- 승리 시 `grantStageClearReward`가 전투 정산과 별도로 최초 스테이지 보상을 지급한다. `claimedStages`에 해당 스테이지가 있으면 이 최초 보상은 반복되지 않는다(434–455, 5535행). 첫 클리어 보상과 전투 종료 정산은 별개이므로 모델에서 합쳐야 하며, 재도전 때는 최초 보상을 0으로 둔다.
- 최초 클리어 기본: `min(110, 22 + (stage−1)×5)`. 15스테이지 주기 안 위치 c가 5 또는 10이면 추가 `105 + min(75,(cycle−1)×15)`, c가 15면 `220 + min(120,(cycle−1)×20)`; c가 2·3·4·7·8·9인 경우 이 추가 DNA는 없고 그 외 c는 `12 + min(36,cycle×4)` 추가. 조건은 실제 else-if 분기를 그대로 반영한다.
- 예: 1스테이지 최초 클리어 38 DNA(22+16), 2는 27, 5는 147(42+105), 10은 172(67+105), 15는 312(92+220). 전투 종료 정산은 별도이며 실제 지급량은 해당 판의 플레이에 달린다.

## 2. 전투 중 확인한 주요 유입 경로

- 기본 `killEnemy`: 일반 약한 적은 매 7번째 처치 시 기본 1 DNA; brute 기본 3, 일부 특수 유형 기본 2, elite 기본 14, finalBoss 기본 40 또는 apex 100. 각 처치에 경로·유물·연속 처치 배율을 곱하고 `Math.round`한다(3618–3642행). 일부 중간보스·페이즈 래퍼는 이 기본 경로를 변경하므로 전부에 적용한다고 가정하지 않는다.
- 유전자 경로의 처치 배율 `1.18×(1+숙련도×0.04)`, 인페르노는 1.12. 유물·연속 처치 보정과 반올림이 개별 처치에 적용된다(1087, 3642행). 모든 이벤트 지급에 동일 배율이 적용되는 것은 아니다.
- 바이오 상자 `10+min(10,floor(stage×1.3))`; 둥지 `16+min(14,stage)`; 구역 이벤트 `round(18+stage×1.8)`; 유전자 균열 `10+5×tier`(1659–1683, 1832–1836행). 활성화·접근 가능 조건을 만족해야 한다.
- 빠른 웨이브·네메시스·중복 기관 등 다른 유입도 있다(1902, 3520, 3624, 5813행). 네메시스는 전투 DNA와 목적 보너스 각각을 따로 추가하므로 중복 취급하지 않는다.
- 성과 보너스는 빠른 웨이브·완벽 회피·연속 처치·블루프린트·네메시스·균열·승리 체력 조건을 합산하고 스테이지별 상한을 적용한다. 패배 시 상한 적용 후 45%의 바닥값을 사용한다(2945–2955행).

## 3. 확인된 DNA 소비처: 상점의 영구 연구

`updateLab`의 연구 구매는 `round(base×[1,1.75,2.9,4.35,6.15][현재레벨]/5)×5`이며, 보유 DNA를 차감하고 레벨을 저장한다. JS 양수 `Math.round` 기준이다(128–129, 509–526행). 만렙·클리어 해금 제한이 있다.

## 4. 유료 설계에 미치는 영향

1. 기기에 저장되는 DNA를 구매 증빙이나 유료 결정의 교환 기준으로 신뢰하지 않는다.
2. 무료 유저의 위 2,590 DNA 연구가 기존과 같이 가능한 상태를 유지한다. 결정으로 직접 공격력·희귀 카드 확률·캠페인 진입을 독점하는 설계는 M01 기준에서 제외한다.
3. 실제 게임 데이터와 성공률이 없으므로 매일 DNA 소득·완주 시간·매출은 아직 알려지지 않았다. 20%에서는 가상의 전투 길이와 수급량을 명시한 조건부 비교만 한다.
4. SKU 가격·수량은 운영 상품이 아닌 30% 초안에서 제안한다. 실제 PG 계약, 세무 및 환불 조건은 미확정이며 결제는 비활성 상태를 유지한다.
5. 실기 Galaxy S23+의 장시간 성능은 미검증이다. 신규 이미지 생성 없음.
