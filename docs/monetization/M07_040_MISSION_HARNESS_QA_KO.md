# EVOLVE M07 40% — 비이미지 연구 미션의 독립 실행 프로토타입
작성: 2026-10-28 KST | M07 STEP 2/3, 40%

## 구현 범위
`monetization/m07/mission-harness-040.cjs`는 **메모리 안에서만 실행되는 테스트 전용 프로토타입**. 기존 `utc-period-planner-v1.cjs`(무료 28일 후보)와 `paid-month-calendar-v1.cjs`(유료 매월 1일~말일 KST)를 재사용한다. 브라우저/게임 렌더러/SHOP/세이브/네트워크/실제 계정·서버 API에 붙지 않는다. `main` 및 공개 Pages 게임은 수정하지 않았다.

`createLocalSeasonHarness({accountId,freeCycleId,freeStartUtc,paidMonth})`를 호출해 **각 테스트 독립** 미션 상태를 만든다.
- 무료: 일일 첫 게임 완료, 일일 스테이지 활동, 주간 도감 발견 3개 미션의 기간별 진행률과 중복 이벤트를 **테스트 입력으로만 시뮬레이션**.
- `previewUnverifiedEvent`: 이벤트를 미검증 상태에 기록하되 진척은 0이고 보상/권리 지급 불가. 재입력은 중복 차단.
- `simulateVerifiedEvent`: 단위테스트용 가상의 검증 승인. 이벤트 ID, 계정/사이클 귀속, 이벤트 종류, 기간·일/주 1회 상한을 검사한 뒤 *미리보기 진척*만 증가. **입력은 실제 서버 검증이 아니므로 게임 보상, 연구 포인트, DNA, 결정을 지급하지 않는다.** 프로덕션에 이 메서드를 직접 연결하는 것은 금지.
- `snapshot(atUtc)`: 명시적으로 전달된 시험 시각 기준 무료 사이클과 유료 KST 월간 경계를 분리. 유료 패스는 항상 `DRAFT_DISABLED`; `checkoutEnabled=false`, `realRewardsGranted=0`.
- `claimReward()` 및 `purchasePass()`: 항상 실패 사유/실지급 0을 반환한다. 실제 결제·영수증·유료 권리 연동 미구현.

## 달력과 보상 경계
유료 시즌패스는 달력 한 달, KST 매월 1일 00:00~그달 말일, 실제 종료는 다음 달 1일 00:00 미포함(윤년·연말 포함). 무료 이벤트는 필요한 경우 선택적으로 28일. **유료 월간 종료 시점에 무료 28일 사이클이 진행 중이면 무료 진척을 종료시키지 않는다.** 구매한 영구 외형의 소유권 삭제도 금지.

달력 도우미/테스트용 미션 엔진은 명시적인 시간 인자만 받고 휴대폰 시계를 실제 지급 근거로 쓰지 않는다. `Z` UTC 인스턴트만 허용하며 잘못된 날짜·시간과 기간 밖 이벤트는 거부. 밀리초까지 포함하는 마지막 1초 경계 처리도 검증한다.
