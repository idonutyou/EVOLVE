# EVOLVE M07 50% — 비이미지 미션 기록·복원 실패 차단 구현
작성일: 2026-10-28 KST | M07 STEP 2/3 50%

## 지금 실제로 구현한 범위
- `monetization/m07/mission-journal-050.cjs` — 이미 확인된 `mission-harness-040.cjs`를 감싸는 **독립 Node 테스트 전용** 이벤트 기록·복원 모듈.
- `createTestJournalSession()`은 계정 ID, 무료 이벤트 고유 ID, 시작일·일수, 유료 대상 월을 고정한 시뮬레이션을 시작한다. 테스트에서 명시적으로 승인시킨 **가상 이벤트만** 저널에 넣는다.
- `exportTestJournal()`은 승인된 가상 이벤트만 포함한 JSON 문자열을 반환한다. **미확인 오프라인 이벤트는 영구 복원되지 않으며**, 복원 후에도 미션 진척 0이다. 이 JSON은 클라이언트 localStorage/실제 서버 DB에 저장되지 않는다.
- `restoreTestJournal()`은 JSON 필드/버전/크기/계정·주기 귀속/이벤트 시각·종류 및 sha256 검사 후 가상 기록을 처음부터 재실행해 진척을 재구성한다. 완전히 유효하지 않으면 **복원 전체를 실패시키고 이전 인스턴스는 건드리지 않는다**.
- SHA-256은 **테스트 파일의 우발적인 손상을 알아보는 검사**이지 실제 계정의 위조 방지 서명이나 서버 검증이 아니다. 사용자가 마음대로 다시 계산한 JSON도 '승인된 테스트 이벤트'처럼 꾸밀 수 있다. **이 기록은 영수증·운영 보상 지급 근거로 사용할 수 없다.**
- `claimReward()`/ `purchasePass()`는 계속 실패/지급액 0이다. 원본 게임 저장키, M03 원장, 유료 상품 소유권·실제 결제/가격은 일절 수정하지 않았다.

## 실패·경계 QA
`tests/m07_050_journal_restore.test.cjs`는 가상 이벤트 5건을 받아 기록→직렬화→복원을 테스트하고, 중복/동일 기간 초과·지나간 기간·다른 계정·다른 무료 시즌·잘못된 시간·예상 외 필드·부분 저장·버전 변조·필드/체크섬 변조·이벤트 복제·중복 진행을 거절한다. 오프라인 미확인 1건은 복원하지 않고 실보상 0을 확인한다. 정상 복원은 원본 시뮬레이터에 영향을 주지 않는다.

**유료와 무료의 기간 분리:** 유료 패스는 한국시간 매월 1일 00시~해당 월 말일까지, 무료 미션은 선택적으로 28일을 사용한다. 10월 유료 월간이 끝나도 28일 무료 이벤트는 계속된다. 영구 유료 외형 소유권은 보존돼야 한다. `season_research_pass_01`의 상태는 `draft_disabled` 유지.
