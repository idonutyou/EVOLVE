## 설계 기준 및 변경 금지

기존 M04 100%의 모의 지급·코어 2종/TEST 결정/저장 격리만 사용한다. 기존 홈 탭 RESEARCH, ORGANISM, BATTLE, MEMORY, CODEX의 **5개를 유지**한다. 상점은 개발자 옵트인 `?evolveMockShop=1`에서 홈에서만 열리는 별도 오버레이로 계획한다. 전투에서 상점 진입 불가. 기존 파츠·무기 인벤토리 `#partsGridV523`와 모의 코어 수집 상태를 합산하지 않는다.

이미 합의된 상품은 5종: 스타터(+75 TEST, 1회), 결정 소형(+100), 결정 중형(+300), 공명 코어(외형), 잠긴 시즌 패스. 심홍 코어는 TEST 결정 **120개**를 사용해 해금하는 보조 외형이다. 실제 KRW 가격/외부 결제/실제 영수증·소유권은 제공하지 않는다. 캐릭터 미리보기는 기존 캐릭터 이미지에 M04의 캐시 발광 레이어만 적용한다.

## 화면 상태도 (모바일)

**HOME → SHOP_LIST → PRODUCT_DETAIL → CONFIRM → PROCESSING → RESULT → PRODUCT_DETAIL**

- 홈의 DEV 상점 버튼에서 시작. 상품 목록 진입시 섹션 제목으로 포커스를 옮긴다.
- 목록에서 상품을 누르면 상세 페이지: 정확한 TEST 지급물, 소유 여부, 사용 가능 이유, 개발용 고지. 상세 뒤로가기는 이전 상품 위치/목록 스크롤을 복원한다.
- 코어 컬렉션은 상점의 별도 섹션: 보유 전 획득 경로, 보유 후 장착, 장착 중 해제. 시즌 패스·거래 기록은 실제 준비될 때까지 비활성.
- 구매/TEST 결정 해금은 언제나 확인/취소를 제공한다. 기본 포커스는 안전한 **취소**. 처리 중 닫기/중복 탭은 막는다. 성공하면 모의 저장 데이터를 다시 읽고 상태를 갱신한다.
- Esc/뒤로가기 우선순위는 **처리 중 차단 → 확인창 취소 → 상세에서 목록 → 섹션에서 홈**. 홈으로 닫으면 이전에 사용하던 홈 버튼에 포커스를 복귀한다.
- 손상된 모의 저장이나 저장 공간 접근 실패는 사용자가 알아볼 수 있는 오류 화면을 띄우고 거래·장착을 막는다. 데이터를 자동 삭제하거나 초기화하지 않는다.

## 모바일·회전·스크롤

| 기준 화면 | 필수 동작 |
|---|---|
| **320×568** | 단일열 상품 카드, 버튼은 설명 아래 전체 너비, 한국어 줄바꿈, 수평 스크롤 없음 |
| **393×852** | 상품 상세/코어 상태가 읽히고, 구매·닫기 버튼이 화면 밖으로 잘리지 않음 |
| **852×393** | 가로 화면에서 모달 내부 세로 스크롤, 원본 캐릭터·게임 UI의 비율 변경 없음 |

주요 터치 대상은 **최소 44×44 CSS px**, 인접 버튼 사이 권장 **8px 이상**. 모달 최대 너비 440px, 상하 안전 영역 `env(safe-area-inset-top/bottom)` 고려. 본문은 최소 12px, 주요 버튼 글씨 최소 13px, 제목 최소 17px 및 줄높이 1.35 이상을 목표로 한다.

스크롤 상태는 **화면 메모리에만** 보관하고 localStorage 키를 추가하지 않는다. 목록→상세→취소/뒤로 이동할 때 선택 상품과 목록 위치를 복원한다. 홈 배경은 모달을 여는 동안 스크롤 체인에서 분리한다. 키보드 표시/방향 회전 시 가능한 높이를 재계산해 활성 컨트롤이 가려지지 않도록 한다.

## 포커스·스크린리더 규칙

- `role=dialog`, `aria-modal=true` 사용. 오픈 시 섹션 제목, 상세 시 상품명, 확인창 시 취소 버튼, 심각한 저장 오류 시 오류 제목에 포커스를 이동한다.
- 열린 오버레이에서 Tab/Shift+Tab이 외부 게임 UI로 나가지 않게 한다.
- 실패 메시지는 `role=alert`, 완료 안내는 `role=status`로 중복 낭독 없이 전달한다.
- 잠금/보유/장착은 **색상뿐 아니라 문구와 disabled 상태**로 구분한다.
- Enter/Space로 주요 버튼 작동. 장착된 코어는 `aria-pressed` 또는 동일 의미 접근성 상태 제공.

## 보안·결제 및 저장 보전

`EVOLVE_DEV_MOCK_STORE_V1`에만 모의 거래, 코어 소유/장착, 테스트 결정이 기록된다. `EVOLVE_V575_TEST_*`, DNA·스테이지·파츠·전투 데이터, M03 유료 원장은 절대 수정하지 않는다. 모의 구매의 고유 요청 ID는 저장 실패 재시도시 재사용하고, 취소시 브라우저 저장 바이트를 그대로 유지한다. 상품 카탈로그 `draft_disabled`, 가격 null, `checkout_enabled=false`를 유지한다. 실결제는 완성 후 M08에서만 연결한다.
