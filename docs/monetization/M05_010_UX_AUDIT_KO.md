## 현행 게임 구조 점검

- 실제 홈 메뉴는 **RESEARCH / ORGANISM / BATTLE / MEMORY / CODEX** 5개다. `#homeTabs`의 버튼을 교체하거나 여섯 번째 탭을 추가하지 않는다.
- 기존 ORGANISM 파츠/무기 인벤토리는 `#partsGridV523`, 정렬은 `#partsSortV523`이며 게임 저장과 연결돼 있다. 코어 발광 소유권은 그와 별개의 M04 모의 저장 데이터다. 두 인벤토리를 억지로 합치지 않는다.
- M04 개발용 진입은 `#m04MockTriggerV616` / 허용 호스트+`?evolveMockShop=1`, 홈 화면에서만 가능. 게임 전투 중 구매/장착은 차단한다.
- 현재 M04 모의 상품 5개(스타터 1회, 결정 소형/중형, 공명 코어, 미완성 시즌 패스)와 코어 2종(공명·심홍)이 실제 기준이다. **기존 상품 ID와 지급 방식은 변경하지 않는다.**

## M05 상품 가치 중심 사용자 이동 경로

**홈 → DEV 상점 → 모의 상점 / 코어 컬렉션 → 상품 상세 → 확인·취소 → 획득 확인 → 코어 장착 → 게임 복귀.**

상점은 상품의 **획득 가치**를 먼저 보여 주고 TEST 결정 잔고를 눈에 띄게 표시한다. 가격을 정하지 않은 판매 후보는 숫자 가격을 꾸며 표시하지 않으며, 실제 구매로 오해할 문구를 쓰지 않는다.

**모의 상점**에는 현재 판매가 가능한 *테스트* 상품만 노출하고, 시즌 패스는 보상 미완성 상태로 ‘준비 중’ 잠금 유지. 스타터 지원 패키지는 아직 실제 게임 전투 보너스를 주지 않으므로 현재 지급되는 **TEST 결정 +75와 개발용 소유 상태만** 솔직하게 명시한다.

**코어 컬렉션**은 별도 화면 섹션이지만 기존 게임 ORGANISM 장비를 대체하지 않는다. 소유 전에는 획득 경로, 소유 후에는 장착, 장착 중에는 해제와 현재 상태를 표시한다. 심홍 코어는 TEST 결정 120개 해금이 필요하고, 공명 코어는 해당 모의 상품 획득이 선행돼야 한다. 기존 캐릭터 원본 + 캐시된 코어 발광을 미리보기로 사용하며 전투 능력치는 변하지 않는다.

**테스트 기록** 탭은 향후 단계의 정보 화면 설계 자리로만 확보한다. M05 10%에서 환불·거래 복구가 구현됐다고 주장하지 않는다.

## 오류·저장 상태 UX

- 구매/결정 차감은 모두 **확인 창**을 먼저 제시한다. 취소는 브라우저 저장 바이트를 변경하지 않는다.
- 저장 공간 오류, 중복 요청, 손상된 저장, 결정 부족, 이미 소유, 보상 준비 중을 구별해 사용자가 이해할 문구로 안내한다. 저장 실패는 절대 성공으로 표시하지 않는다.
- 재시도는 원래 요청 ID로 처리해 중복 지급을 막는다. 손상된 테스트 저장은 덮어쓰거나 자동 초기화하지 않고 **읽기 전용·획득 차단**으로 표시한다.
- 테스트 프로필 초기화는 두 번 확인하도록 하고, `EVOLVE_V575_TEST_*`, 무료 DNA, 스테이지·보스·맵·기존 파츠/무기 데이터를 건드리지 않는다.
- 닫기 시 홈 화면의 마지막 포커스로 돌아가며 구매 확인이 진행 중이라면 닫기를 우회해 결제가 진행되지 않아야 한다.

## 모바일 화면·접근성 설계

- 자동 테스트 기준: **320×568, 393×852**. 메뉴 전체를 늘리는 대신 모달 내부만 스크롤하고 안전 영역(safe-area)을 존중한다.
- 모든 주요 터치 버튼 목표 크기: **44×44px 이상**. 글자가 가로로 넘치면 줄바꿈을 허용하며 한글 가독성을 우선한다.
- 키보드 Tab 포커스 루프, Esc의 확인 취소 우선, 닫기 뒤 포커스 복귀, 상태 메시지 접근성 역할을 유지한다.
- 실제 Galaxy S23+ FPS/발열 및 장시간 안정성은 자동 브라우저 검사와 별개다.
