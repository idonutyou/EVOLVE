## 이번 작업의 실제 코드
- `web/mock-premium-v615.js`: Node/브라우저에서 재사용 가능한 **MOCK_ONLY** 엔진. `createStore({storage,enabled:true})`가 아니면 기능 활성화 안 됨. 브라우저 전역 API는 개발 호스트에서 URL에 `evolveMockShop=1`이 있을 때만 노출.
- 아직 `dist/index.html`이나 기존 메인홈의 버튼에서 스크립트를 로드하지 않는다. **이번 40%는 구매/획득/장착 상태 처리 코드이며, 실제 게임 UI로 구매 버튼을 연결한 상태가 아니다.** 이는 50% 목표.
- 별도 `EVOLVE_DEV_MOCK_STORE_V1` localStorage 키. `EVOLVE_V575_TEST_*` 기존 저장, 무료 DNA, M03 프리미엄 지갑, `dist/`/게임 엔진/이미지 변경 없음.
- 5개 내부 SKU를 개발용 상품으로 매핑: 스타터 1회=75 테스트결정/시험용 권리; 결정 소형=100, 중형=300 테스트결정; 코어 외형=시험용 권리/코어 장착 상태(실제 외형 이미지 구현 전); 시즌 패스는 보상 콘텐츠 없어서 **구매 차단**.
- 상품 수량은 **개발용 가정**이고 실판매 가격/실제 유료 재화가 아님. `mockOnly=true`, `source=dev_mock`, `devmock_` ID 영수증은 다른 원장·계정과 통합 금지.
- 구매 재시도 시 동일 request ID는 결과 재사용, 다른 SKU로 같은 ID 재사용은 거절. 스타터·코어 외형은 1회 제한. 존재하지 않는 상품·불완성 콘텐츠·잘못된 계정/ID 차단. 최대 500건 테스트 영수증, 잔고 overflow 차단.
- 코어 테마는 **모의 소유권·장착 저장만** 구현. 게임 캐릭터의 렌더링 이미지는 바꾸지 않는다. 실제 변이 코어 아트/장착 메커니즘은 이후 유료 콘텐츠 단계에서 연결.
