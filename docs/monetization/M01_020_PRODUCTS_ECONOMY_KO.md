# EVOLVE — M01 20% 수익화 우선 제품·경제 모델
작성: 2026-10-27 KST | 신규 렌더링 **불필요** | 모든 SKU·가격은 **제안/비활성**
목표: 게임에 돈을 쓸 이유가 존재하도록 **성장/보상/반복 플레이/상점/연출을 수익화에 맞춰 먼저 설계**, 실제 결제는 안전한 API/원장을 갖춘 뒤 활성화한다.

## 1. EVOLVE의 수익화 핵심 구조
**구매의 주된 이유:** 멋진 변이체를 수집하고, 원하는 전투 스타일을 빠르게 완성하고, 반복 성장의 선택지를 넓히는 것.
**방향:** F2P + 한 번의 명확한 첫 구매 + 지속적인 선택형 소액 구매 + 보상형 광고 + 훗날 검증된 시즌 패스.
**금지:** 유료 구매 없이는 주 캠페인/TITAN 공략 불가, 임의 실패 유도, 결제/광고 버튼 강제, 과도한 랜덤 유료 뽑기, 결제 없이 모든 기본 강화 카드 확률을 고의로 떨어뜨리기.

## 2. 재화 계층 (우선 분리 설계)
| 재화 | 획득 | 소모 | 보안/저장 |
| --- | --- | --- | --- |
| 기존 DNA | 전투·보상 등 기존 게임 동작 | 현재 존재하는 무료 연구/상점 기능의 실제 경로를 후속 감사 | 기존 `localStorage` 유지, **유료 구매 사실의 근거로 절대 사용 금지** |
| 변이 결정 (가칭 `mutation_crystal`) | **검증된 유료 주문**, 한정된 미션 무료 지급, 승인받은 보상형 광고 SSV | 지정된 코스메틱/연구 편의/정량 번들(가격표 서버 확정) | **서버 권위의 미변조 장부·잔고**, 단말은 캐시/UI만 |
| 유료 권리 (`entitlements`) | 검증된 비소모성 IAP/웹 결제 | 구매한 배경/스킨/테마·편의 기능 사용 | 계정 기준, 중복 구매 시 재지급 금지, 플랫폼 정책에 맞춘 재설치 복원 |
| 미션 보상 토큰/패스 점수 | 게임 내 완료 조건 | 기간 내 트랙 보상 청구 | 완료 증거 서버 검증 가능 범위 한정; 브라우저 조작 가능한 전투 클레임은 제한·재검증 |
**DNA↔변이 결정 직접 교환은 출시 초기 비활성**: 브라우저 저장 DNA 위조가 프리미엄 밸런스/매출 악용으로 번지지 않게 한다.

## 3. MVP에 넣을 확정형 구매 후보 (가격은 시험값, 스토어 지역별 실제 가격 미등록)
| 순위 | SKU 제안 | 소비형 | 표시 가격(예시, KRW) | 구매 가치 | 무료 유저 영향 |
| --- | --- | --- | --- | --- | --- |
| 1 | `starter_genome_once` 초회 돌연변이 지원팩 | 계정 1회 | 2,200원 | 확정 변이 결정 + 기존 전투에서 유효한 별도 편의권 한 번(정량 공개). 기본 DNA와 구분 | 필수 성장·스킬 차단 없음 |
| 2 | `mutation_crystal_small` 결정 소량 묶음 | 소모 | 3,300원 | 고정 수량의 유료 결정 | 동일 소비처로 무료로도 천천히 접근 가능 |
| 3 | `mutation_crystal_mid` 결정 중량 묶음 | 소모 | 6,600원 | 고정 수량, 단가 공개 | 없음 |
| 4 | `appearance_unlock_01` 기지 UI/진화 코어 테마 | 비소모 | 4,400원 | 확정 외형·화면 테마(기존 리소스 변형/색상 매개변수 가능 시 신규 이미지 불필요) | 전투 스펙 증가 없음 |
| 5 | `season_research_pass_01` (후순위 조건부) | 시즌 | 미정 | 매 시즌 완주 가능한 무료/유료 트랙, 무료 트랙에도 성실한 보상 | 출시 초반 도입 서두르지 않음 |

- 위 수량·할인율·가격은 **판매 확정이 아님**. M02에서 무료 DNA 유입량, 잔고 변화, 상점 효용, 전투 난도 시뮬레이션 후 정한다.
- 결제 공급자에 등록되기 전 어떤 SKU도 누르기만 해서 유료 재화를 생성하지 않는다.
- '3,300원 2배 효율' 같은 가치를 표시하려면 실제 가격·기준량·출시 정책 검증 후에만 계산.
- 결제자라도 이전 V614의 장착 ARM 잠금, 입·가시·채찍 공격 성장, 전격 해금, Lv3/Lv6 진화 규칙은 변경 불가(유료 구매로 독립적으로 연동할 경우 별도 최종 확정 후).

## 4. 재방문/광고 후보: 무료와 결제를 함께 성장시키기
- **선택형 보상 광고 1:** 전투 **종료 후** DNA 또는 소량 비유료 보상 추가. 실제 전투 도중 화면 위에 광고 배치 금지.
- **선택형 보상 광고 2:** 스테이지 클리어 후 단일 연구재료 추가 또는 제한된 '재도전 보상' 기회. 보스전 중 광고 노출·강제 부활·대미지 즉시 구매는 초기에 제외.
- 하루 광고 시도·보상 지급은 서버측 사용자/placement/transaction/UTC day 기준 제한, 미시청·네트워크 실패는 보상 0. 광고 미승인·사용자 거부 시 정상 플레이 가능.
- H5 광고 제공자 가입/승인은 운영자 준비 필요. 제3자 광고 검증값을 브라우저의 허위 callback으로 대신하지 않는다.
- **초회 구매 유도 타이밍:** 첫 전투 경험/스킬 하나 습득 후, 상점에 사용처가 실제 생겼을 때만 간결하게 한 번 소개. 막 시작하자마자 결제창 덮기 금지.
- **반복 구매 동기:** 수집 테마, 연구 선택지, 난도별 스킬 실험, 시즌별 특화 빌드. 결제를 해도 전투를 자동 승리하는 '전투 파워 팔기'가 되지 않게 유효성 시뮬레이션.

## 5. 수익/품질 지표 (측정만, 목표값은 운영 전 미확정)
- 결제 퍼널: 상점 진입→상품 노출→세부 확인→결제 시작→외부 승인→서버 검증→지급 완료; 각 전환 손실과 retry 중복 수.
- 플레이 건강: D1/D7 유지율, 재방문, 전투 3/5분 버그(실기 미해결), 퍼널 이탈·환불/문의·무료 유저 이탈, 평균 세션 길이.
- 매출: 결제자 비율 = 고유 결제자 / 해당 기간 사용자; ARPDAU=세금/플랫폼 수수료 전후 구분한 일매출/DAU, ARPPU=결제자 기준 일매출/결제자; 광고 eCPM 수입, 네트워크 비용, 차지백/환불 제외 순매출 별도.
- 안정성: 영수증 위조 지급 0, 웹훅 재전송 중복 지급 0, 환불 취소 후 권한 재생성 0, 구매 후 새로고침/재설치 지급 누락 0, 저연령/개인정보 동의 문제 0.
- 숫자 KPI는 초기 소규모 실제 사용자 데이터 없이 '목표 달성' 또는 예상 매출 확정으로 표기하지 않는다.

## 6. 전체 설계에 미치는 실제 변경
- **STEP09~17 카드/진화:** 유료 진화 필수화 금지. 진화 수집 목표와 무료 플레이어의 핵심 게임 루프에서 보상 설명/상점 연계.
- **STEP18~26 융합/보스:** 최초 발견·클리어 보상을 프리미엄 수집/코스메틱/연구 미션과 연결; 유료 아이템만 있어야 융합 가능하게 하지 않음.
- **STEP27~29 맵:** 반복 진입의 장기 목표/미션·보상(서버 확인 가능한 정보만 프리미엄 지급)과 연결.
- **STEP30~34 영구 성장:** 장비/도감/연구 트리→구매한 코스메틱 권한 표시/재화 소비처, DNA 레거시 저장 마이그레이션과 계정 연동이 특히 중요.
- **STEP35~39 기록/도전:** 전투 종료 후 자연스러운 무료 보상·선택 광고·상점 제안 위치, 청구 횟수/재보상 제한.
- **STEP40~43 안정화:** 결제 인증·복원·환불·구독 해지(후일)·개인정보·광고 동의·스토어 심사/플랫폼 분기 포함, 장기 FPS 문제도 별도 유지.

## 7. 우선 실행 전제
1. M01 제품/플랫폼 정책 및 경제 전략 → M02 숫자/상품/소비처 → M03 안전 원장/인증/재설치복원 → M04 첫 웹 주문 샌드박스/실결제 경로 → M05 상점/첫 구매 UI와 안정화 → M06 광고 → M07 재방문/시즌 → M08 출시·대시보드·환불·정책 게이트.
2. M02부터 모든 변경은 "이게 유료 상품 구매 이유/건전한 무료 루프/수익 지표에 어떤 영향을 주는가" 점검.
3. 모든 M단계 3회 구간(10~30/40~70/80~100), 원격 복구 10% 기준. 대용량 이미지 생성은 사전 예고.
4. 실제 결제 제공자 계약/비밀키가 없으면 샌드박스까지 만들 수 있으나 실매출 보증/완료 주장 금지. GitHub Pages 공개 코드에 키를 넣지 않는다.
