## 실제 구현 범위 및 한계
- 기존 M08 10/20% 두 브리지와 기존 원본 게임·상점 코드는 변경하지 않음.
- 두 연구 모듈은 읽기 전용 로컬 UI 관찰이며 서버 인증이 아님. 런 결과 화면이 나타났다는 사실은 실제 승리 인증과 다르다. 도감 화면의 발견 수 변화 역시 별도 서버 증명이 아님.
- 보상, 실제 결제, 게임 DNA 지급, 운영 권리 검증은 이번 단계에서 연결하지 않음.
- 브라우저 검사는 화면 진입 및 DOM 연동을 검증하며 실제 타이탄 격파까지 자동 플레이한 검사가 아님.
- Galaxy 물리 실기기 검사는 아님. 공개 Pages 배포하지 않고 브랜치에서만 테스트.
