## 직접 구현한 UX

1. **상세 화면의 보유 상태**: 미보유 → 보유 중 → 장착 중을 실시간 모의 지갑으로 표시. 코어 상품은 구입하면 곧바로 **장착** 버튼, 장착 후엔 **해제** 버튼으로 변경. 실구매 버튼인 양 꾸미지 않음.
2. **상세에서 즉시 코어 전환**: 공명 코어의 장착/해제는 M04 실제 검증 엔진으로 위임하며 `aria-pressed`로 장착 상태를 구분. 별도 **코어 컬렉션 보기** 버튼 연결.
3. **컬렉션 동기화**: 보유 코어 수량 0~2개, 카드별 ‘미보유/획득 완료/장착 중’, `data-owned`, `data-equipped` 접근 가능 상태 표시. 공명 코어 미보유 시 ‘상품 상세에서 획득’ 바로가기. 심홍 코어의 원래 **120 TEST 결정으로 해금** 버튼의 접근성 이름을 유지.
4. **반복형 TEST 묶음**: 이미 시험 지급했더라도 ‘다시 모의 획득’ 표시. 1회 스타터 패키지는 소유 시 ‘보유 중’ 고정. 준비되지 않은 시즌 패스는 계속 잠금.
5. **개발 모드 격리**: `?evolveMockShop=1&evolveM05UX=1` **둘 다** 필요. 일반 주소와 원래 M04 전용 URL은 M05 확장 UI를 표시하지 않음.
