# EVOLVE M08 10% — 실제 스테이지 진척과 CHALLENGE 연결 (간소화 작업 1차)
2026-10-28 KST

## 실제 구현
- `web/m08-stage-mission-v622.js` + 동일 `dist/m08-stage-mission-v622.js` + `dist/index.html` 한 줄 로드: 기존 HOME **CHALLENGE** 안에 스테이지 클리어 임무 카드 표시.
- `window.__EVOLVE_ADMIN_MODE_V585__.read().normal.unlocked`를 실제 게임의 로컬 진행 이벤트 후보로 사용. 최초 확인한 해금값을 기준선으로 저장하고, **이후 새 스테이지가 정확히 한 단계 해금**되면 해당 클리어 스테이지를 중복 없이 기록한다.
- 한국시간으로 오늘 새 클리어가 있으면 임무 진행률 1/1 표시. 과거 클리어는 소급 처리하지 않고, 새로고침 후 진행 기록은 별도의 `EVOLVE_M08_STAGE_MISSION_V622_V1` 로컬 저장소에 보존한다.
- 관리자 모드 활성화 중 관찰된 진행, 비정상 해금 단계 점프, 이미 기록한 동일 스테이지는 **새 미션 진행으로 인정하지 않음**. 저장 데이터가 손상되면 자동 초기화/삭제하지 않는다.
- **현재는 임무 진행 UI와 기록만 연결**했다. 보상은 지급하지 않는다. 이 로컬 이벤트는 조작 가능하며 **서버 검증/실제 플레이 증명/실결제 권리 지급으로 사용 금지**. 다음 20%에서 플레이 및 보상 동선 심화 예정.
- 기존 SHOP, 시즌 패스, 코어 외형, 실제 전투·몬스터·캐릭터·원본 이미지/세이브 등은 수정하지 않는다.

- 범위를 줄였어도 원본 게임 보호 경로는 집중 CI에서 **반드시 차단**. 배포 전에 최소 GitHub Actions PASS를 확보한다.
