# EVOLVE WEB-23 — 이동 방향과 방전 장치

- 본체는 실제 이동 방향을 바라본다. 공격 대상 때문에 본체가 돌아가지 않으며, 기존 좌우반전·기울기·뒤집힘 제한을 유지한다.
- 칼·총은 마지막 공격 방향을 2초 유지한다. 그 사이 다시 공격하면 2초를 다시 센다. 추가 공격이 없으면 현재 이동 방향으로 돌아온다. 일시정지 중에는 유지 시간도 멈춘다.
- 방전 장치의 확산 시간을 0.52초에서 0.78초로 늘리고, 중심 띠를 기존 4에서 12 월드 픽셀로 굵게 했다. 밝은 전기 선과 외곽 방전을 추가했다. 충전에 필요한 3초와 파동이 지나갈 때 한 번씩 피해를 주는 규칙은 유지한다.
- 사용 후 재생성은 20초에서 60초로 늘렸다. 활성 장치는 하나만 존재한다.
- 생성은 화면·캐릭터 주변 반경 제한 없이 맵 전체를 대상으로 한다. 실제 플레이어의 발 충돌로 갈 수 있는 연결된 바닥에서만 뽑고, 장치 전체의 여유 공간도 검사한다. 벽 뒤로 길이 연결된 곳에는 생성할 수 있으며, 고립된 구역·벽·시설 내부에는 생성하지 않는다. 유효한 위치가 없으면 기다린다.
- 이동 가능 영역은 캐시하고 맵이나 연결 구역이 바뀌면 다시 구한다. 매 프레임 전체 맵을 검사하지 않는다.

## 검사

총과 칼로 이동 반대 방향을 공격하는 실제 전투, 공격 방향 2초 유지와 복귀, 재공격과 일시정지를 검사했다. FACILITY1·FACILITY2·HUB·BIOLAB·RED BIOLAB에서 실제 장치 생성 48회씩 총 240회 검사하여 도달 가능성·여유 공간·먼 위치 생성·중복 방지를 확인했다. 파동 속도와 굵기, 기존 칼·총 명중 및 저장, 맨손 공격과 다섯 시작 공격 검사도 통과했다. 기존 이미지 994개의 바이트와 맵 충돌 데이터는 유지했다.

온라인 배포와 실제 사이트 파일 검증은 배포 완료 기록으로 확인한다. Galaxy S23+ 실기 검사는 수행하지 않았다.
