# STEP 07 — 20% 구현 설계 · 피격/사망 피드백
작성일: 2026-10-27 KST · **설계 문서** (코드 적용 전)

## 범위/비범위
- 일반·신규·변형·정예/중간보스 **몬스터**의 시각적 피격 및 사망 표현만 개선.
- 7종 TITAN과 기존 보스 페이즈/죽음/보상 연출은 보존하며 **이번 단계의 변경 대상에서 제외**.
- 체력, 데미지, 치명타, 경직 판정, 실제 이동·넉백, 공격 딜레이, 경험치, 아이템 드롭, 탄막 충돌, 경고 레이어, 그림자·HP바 레이아웃을 변경하지 않는다.
- 플레이어 피격·장비·신체 이미지·기존 사용자 맵·저장 키도 변경하지 않는다.
- 신규 렌더 이미지/스프라이트 생성 **필수 아님**. 4프레임 몬스터 아틀라스와 기존 사망 잔상 이용. 시각 품질 미달이면 해당 이미지 종류를 사전 고지하고 *별도 사용자 요청을 기다리지 않고 진행 여부 결정* (기존 확정 디자인 보존).

## 이벤트 소스/우선순위
1. 수신은 기존 `EVOLVE_HIT_EVENTS` schema 1의 `type='hit'`, `damage>0`, `event.killed`, `event.kind`, `event.weapon`, `event.angle`, `event.knockback`을 **읽기 전용** 활용한다. `shield`, 0 피해, DOT 반복, 불일치·무효 대상은 일반 피격 재트리거하지 않는다. DOT는 작은 지속 표시가 이미 있으면 유지하되 새 순간 충격 생성 금지.
2. `STEP05` 총/칼 `pose`, `STEP06` 가시/채찍 `pose`, 기존 `arcShockV576` 반응이 활성일 때 **신규 신체 변형을 합성하지 않는다**. 신규 fallback은 이미 구현된 4프레임 hurt/기존 피격 타이머를 보완하는 범위다. `weapon` 종류 판단은 실제 이벤트 메타데이터 기반이며 총/칼이 아닌 입 공격을 총/칼처럼 꾸미지 않는다.
3. 전조 중인 중간보스와 위험 공격은 명확한 경고가 우선. 피격이 와도 경고 레이어·공격 방향을 보존한다. 최종 draw 순서에서 붉은 공격 경고는 피격 효과보다 위쪽에 남는다. 기존 전격장비 잠금은 유지한다.
4. 사망은 1회만 시각 처리한다(`dead` 전환 또는 `event.killed`만 기록). 기존 `spawnDeathEcho` 하나를 받아 **그림·수명·velocity/spin 설정만 제한적으로 보정**하며 별도 잔상/파티클 풀을 추가하지 않는다. 기존 죽음 잔상이 생성되지 않은 분기에서만 기존 안전한 fallback을 호출; 보스/TITAN 및 특별 사망 시스템을 건드리지 않는다.
5. `WeakMap`/제한된 `Set`으로 활동 중 유효 대상만 참조하고 만료·dead·귀환·재시작/새 판 때 비운다. 몬스터 수 증가와 비례하는 무제한 신규 파티클을 금지한다.

## 성능·접근성 안전장치
- 신규 피격 효과 **추가 발광 이미지 0개**. V612·V613이 이미 제한하는 공유 효과 48(군중 시 28/모션 감소 시 16) 상한을 넘기지 않음.
- 새 포즈 계산은 프레임당 활성 타깃만 조회하고, 몬스터별 과도한 새 배열/Canvas/텍스처 생성 금지. 동시 새 추적 타깃 제한 **24**부터 시험; 몬스터가 180마리 이상이면 12~16으로 축소 시험.
- 화면 밖은 별도 피격 그림을 추가하지 않고 일반 렌더링 skip/culling 그대로 사용. 기존 `monsterSurfaceV577` 캐시/아틀라스 40프레임을 유지.
- 모션 감소 시 신체변형/회전 제거, 기존의 최소 시각 인지만 허용. 플래시 강도 0이면 신규 백색 화면/큰 이펙트 0개.
- 시간 기반 시각 모션은 실제 전투 가동 시간에만 진행; `paused`, `choosing`, `rewardChoosing`, `ended` 중 타이머 증가·죽음 잔상 움직임이 부자연스러운 부분은 **시각 레이어에서만** 수정. 기존 적 전투 로직의 dt 변경 금지.
- `gpuEnemyVisualV426`과 Canvas `drawEnemy`가 동일 포즈 수치로 표현되는지 각각 확인. 그림 중심과 바닥 접지점 유지; body collision/radius unchanged.
- 카메라 전체 흔들기 없음. 체력바 숫자·좌표·Z순서 및 붉은 경고 레이어 변경 없음.
