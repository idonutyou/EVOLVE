# EVOLVE WEB-22 — 칼·총 아이템 완성본

기준: 온라인에 배포된 WEB-21. WEB-22 구현과 자동 검사를 완료했다. 사용자가 자동 업로드·배포를 명시적으로 지시하여 배포와 실제 사이트 검증을 진행한다.

- **생체 쌍포**: 파츠 화면에서 장착하면 앞발에 쌍포가 표시된다. 전투에서 ARM을 선택하면 양쪽 총구를 번갈아 사용한다. 기존 탄환·명중·관통·다중 탄막·별 등급 강화를 그대로 사용한다.
- **절단 쌍날**: 앞발의 칼날을 번갈아 휘두른다. 준비 동작 뒤 칼이 지나가는 전방 범위의 적들을 한 번씩 벤다. 뒤쪽·사거리 밖·구조물에 가린 적에게는 피해를 주지 않는다.
- **아이콘**: 표시 없는 원본에서 빨간 표시에 해당하는 앞쪽 총구·칼날만 추출했다. 원본 RGB와 세부 묘사를 유지하고, 검은 배경과 상단 팔의 떨어진 조각을 제거했다.
- 장착·교체·해제 결과가 기존 ARM 슬롯에 저장된다. 해제하면 기존 두 앞발의 교대 찌르기로 돌아간다.
- 홈과 전투 모두 장착 외형을 표시한다. 기존 캐릭터 원본·앞발/코어 위치·좌우반전과 기울기 제한을 유지한다.
- 전격은 계속 잠겨 있다. 다른 시작 공격, 맵, 보스와 저장 키는 유지한다.

## 확인한 결과

탄환의 실제 이동과 명중, 별 등급별 탄수·관통 증가, 칼의 준비 시간·다수 타격·한 번만 타격·좌우 교대·빗나감·벽 차단, 저장 후 재접속과 장착 해제를 검사했다. 기존 다섯 공격, 원본 캐릭터와 모션, 일반/관리자 모드, 맵·보스·경고 표시, 저장과 안전한 업데이트 검사도 통과했다. 기존 이미지 988개의 파일 바이트는 유지했다. 새 외형은 20개 포즈를 한 번 준비하고 그리는 동안 다시 만들지 않는다.

모바일 세로·가로 화면을 자동 검사했다. 실제 Galaxy S23+ 성능과 조작감은 아직 확인하지 않았다.

## 남은 단계

이 완성본을 기존 `idonutyou/EVOLVE`에 자동 업로드하고 GitHub Pages의 실제 배포 버전과 파일 해시를 확인한다. 앞으로도 EVOLVE 수정이 끝나면 별도 확인 질문 없이 자동 업로드·배포한다. 실제 배포 검증이 끝나기 전에는 온라인 반영 완료로 보고하지 않는다.
